# Windsurf IDE

## When to Use
需要轻量级AI IDE且偏好Codeium生态时；需要Cascade多轮对话式编程辅助；希望体验级联式AI工作流。

## Core Features
- **Cascade对话流**：底部面板持久化对话，可多轮追问、上下文自动携带
- **Model Tab**：可切换不同模型（Codeium Base/Pro/Max）
- **Codeium基础**：集成Codeium引擎，上下文理解能力较强
- **文件操作**：直接用自然语言要求创建/修改/删除文件
- **终端集成**：Cascade可执行Shell命令并解读输出
- **会话管理**：支持保存/加载对话会话

## Quick Start
1. 安装Windsurf，启动后打开项目目录
2. 底部"CASCADE"面板输入需求
3. AI分析后可直接点击"Apply"应用到文件
4. Model Tab切换模型版本

## Pitfalls
- Cascade默认生成代码直接修改文件，需确认再应用
- 国内下载速度慢，建议科学上网
- 对大型项目索引时CPU占用较高
