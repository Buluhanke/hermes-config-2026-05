# HeyGen

## When to Use
需要快速生成数字人播报视频时；产品介绍、培训视频、营销内容；需要API批量生成视频。

## Core Features
- **数字人选择**：100+虚拟形象，支持多种语言和肤色
- **语音合成**：输入文字转数字人配音
- **视频模板**：预制模板快速套用
- **API支持**：PPLX-API风格的REST API，批量生成视频
- **免费额度**：新用户赠送免费分钟数
- **定制数字人**：可上传照片创建类己数字人

## Quick Start
1. 注册heygen.com，进入Dashboard
2. 点击"Create Video"选择数字人，输入脚本
3. 选择语言、背景、字幕后生成
4. API用户：在Settings获取API Key，调用/api/v1/video接口

## Pitfalls
- 免费额度仅支持低分辨率导出
- 数字人口型偶有不同步
- API生成视频为异步，需轮询状态
- 商业使用需购买付费套餐
