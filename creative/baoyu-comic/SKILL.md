# baoyu-comic · 知识漫画生成

## When to Use
- 采购培训、新员工 onboarding、内部知识分享
- 供应商故事、产品介绍、流程说明
- 1688商品主图/详情页卖点可视化

## Comic Style Templates

### 四宫格（叙事型）
上→下/左→右：起因→转折→高潮→结局。适合流程、议价过程。

### 条漫（连载型）
垂直长图，每格 300-500px 高，适合朋友圈/企微传播。

### 信息图漫画
左图右文/上表下图，适合供应商档案、产品卖点汇总。

## Character Consistency
- 每次生成用固定描述词绑定角色外形（身高/发型/服装颜色）
- 示例：`[采购员A: 中年男性, 微胖, 黑色公文包, 蓝色西装, 始终不变]`
- 多角色场景：每人在 prompt 中占独立段落，复制粘贴不混用

## Prompt Templates

**基础句式：**
```
[场景描述], [角色描述], [情绪], [动作], [背景], [画风: 扁平商务插画/日系/国潮]
```

**示例（四宫格·议价场景）：**
```
格1: 采购员走进供应商展厅，表情期待，日式扁平插画
格2: 供应商报价，采购员眉毛上扬，表示惊讶，日式扁平插画
格3: 双方坐下谈判，采购员手指表格，表情严肃，日式扁平插画
格4: 握手成交，两人微笑，背景工厂仓库，日式扁平插画
```

## Chinese Business Scenarios

- **1688商品介绍**：产品实拍图→卖点漫画图→应用场景图，三格
- **供应商拜访**：出发→到达→洽谈→签约，四宫格
- **议价拉锯**：供应商报价→成本拆解→让步→成交
- **验货场景**：到货清点→抽检→合格入库→问题处理

## Tools

- **Canva**：PPT插件/在线上传图片，适合快速生成条漫
- **PowerPoint**：插入形状+文字，母版复用，四宫格效率高
- **Miro**：白板协作，团队共同编排故事线，适合策划阶段

## Pitfalls
- 角色形象前后不一致 → 每次生成锁定角色描述词
- 中文文字在图片中难以修改 → 优先图片+外链文字说明
- 画风混乱 → 全程统一「日式扁平」或「商务插画」一种风格
- 生成版权风险 → 避免实拍人物面孔，优先用插画角色
