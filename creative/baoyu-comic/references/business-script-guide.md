# Business Scene Script Generation Guide

Create narrative scripts for business scenario comics — B2B sales, negotiation, client meetings, internal communications.

## Content Type Profile

| Attribute | Value |
|-----------|-------|
| Triggers | 商业场景剧本、职场漫画、销售故事、客户沟通、商务谈判 |
| Art Style | manga (default), ligne-claire |
| Tone | warm (default), dramatic |
| Layout | standard (default), cinematic |
| Aspect | 3:4 (portrait) |
| Page Count | 6-16 pages |

## Script Beats (Scene Progression)

### Beat 1: Opening [Page X-Y]
**Objective**: Establish scene, introduce characters

```
[Character A]: [Opening line - greeting, context setup]
[Character B]: [Response - establishes their role/need]
```

**Visual Direction**: Establish setting, character introductions

### Beat 2: Discovery [Page X-Y]
**Objective**: Uncover buyer needs, build rapport

```
[Character A]: [Question to understand pain points]
[Character B]: [Reveals challenge or need]
```

**Visual Direction**: Close-up expressions, notepad or data visualizations in background

### Beat 3: Solution Presentation [Page X-Y]
**Objective**: Present the value proposition

```
[Character A]: [Introduces solution with benefit framing]
[Character B]: [Shows interest / asks clarifying question]
```

**Visual Direction**: Product/service visualization, demo element

### Beat 4: Objection Handling [Page X-Y]
**Objective**: Address concerns, build credibility

```
[Character A]: [Handles price/quality/timing objection]
[Character B]: [Still skeptical OR accepts reasoning]
```

**Visual Direction**: Conflict tension in expressions, counter-argument visuals

### Beat 5: Value Reinforcement [Page X-Y]
**Objective**: Emotional appeal, relationship building

```
[Character A]: [Story, case study, or trust signal]
[Character B]: [Softening, building trust]
```

**Visual Direction**: Warmer tones, collaborative body language

### Beat 6: Call to Action / Close [Page X-Y]
**Objective**: Define next steps

```
[Character A]: [Clear next step: sample order, follow-up meeting, proposal]
[Character B]: [Acceptance or commitment]
```

**Visual Direction**: Handshake, exchanged contact, forward momentum

## Dialogue Writing Principles

### Business Dialogue Rules

| Rule | Description | Example |
|------|-------------|---------|
| Subtext | Characters say one thing, mean another | "Your price is interesting." (= it's too high) |
| Specificity | Use concrete details, not vague terms | "Three containers per month" not "regular orders" |
| Benefit-first | Lead with buyer value | "Save 30% on logistics" not "We have good freight rates" |
| Question rhythm | Alternate questions and answers | Discovery: A asks, B answers. Proposal: A presents, B reacts. |
| Silence as beat | Use "[pause]" or "[silence]" for dramatic effect | "[Silence] ... Let me check with my team." |

### Language Adaptation by Market

| Market | Style | Example Phrasing |
|--------|-------|-----------------|
| 中国B2B | Direct, relationship-focused | "咱们先喝杯茶，慢慢聊" / "这个价格确实有空间" |
| 东南亚 | Relationship-first, formal titles | "Mr. Tan, may I present..." / "Let me consult with my superiors" |
| 欧美B2B | Efficiency-focused, data-driven | "Based on your specs..." / "ROI analysis shows..." |
| 日本 | Formal, indirect disagreement | "それは難しいかもしれません" / "検討させていただきます" |

## Character Archetypes for Business Scripts

| Role | Description | Dialogue Style |
|------|-------------|----------------|
| 销售工程师 | Technical seller, problem-solver | Asks diagnostic questions, translates features to benefits |
| 采购决策者 | Cost-focused, riYOUR_API_KEY | Asks "what's the catch?", needs assurance |
| 技术对接人 | Detail-oriented, specification-driven | Asks "how does it work?", needs proof |
| 老板/决策人 | Outcome-focused, time-poor | Asks "what's the bottom line?", needs efficiency |
| 竞争对手 | Proxy or reference | Often absent but referenced ("We had a vendor who...") |

## Visual Storytelling for Business Scripts

### Panel Composition for Professional Settings

| Business Scenario | Visual Approach |
|------------------|-----------------|
| First meeting | Wide establishing shot, neutral ground (meeting room, café) |
| Product demo | Close-ups on product, screen share visualization |
| Negotiation | Two-shot composition, maybe split panel showing both sides |
| Virtual meeting | Screen within screen, chat bubble overlays |
| Factory/warehouse visit | Environmental establishing shot, worker characters |
| Trade show | Crowded booth scene, flyer/sample prop visuals |

### Business Script Color Grading

| Scene Type | Color Treatment |
|-----------|----------------|
| Opening/Discovery | Cool blues, professional, slight desaturation |
| Solution presentation | Warmer tones, confidence building, brand accent colors |
| Objection/Tension | Slightly high contrast, muted colors, tension in composition |
| Close/Agreement | Warm lighting, open composition, forward motion |
| Internal meeting | More casual, collaborative warmth |

## Scene Types & Templates

### Scene Type 1: First Meeting (首次拜访)

```
Structure: 6 pages
Page 1: Scene setting, both characters enter
Page 2: Ice breaker, rapport building
Page 3: Discovery questions, buyer reveals needs
Page 4: Initial solution framing
Page 5: Objection or concern raised
Page 6: Next step agreed, optimistic close
```

### Scene Type 2: Product Demo (产品演示)

```
Structure: 8 pages
Page 1: Demo setup, technical buyer introduced
Page 2-3: Core feature demonstrations (2 pages)
Page 4: Live test or interactive element
Page 5: Comparison with alternatives
Page 6: Technical specs / data backing
Page 7: Q&A, addressing concerns
Page 8: Demo success, next steps
```

### Scene Type 3: Negotiation (商务谈判)

```
Structure: 10 pages
Page 1: Negotiation setting, both parties seated
Page 2: Opening positions stated
Page 3-4: First round of back-and-forth (2 pages)
Page 5: Escalation or concession made
Page 6-7: Creative problem-solving (2 pages)
Page 8: Near-agreement, small gap remains
Page 9: Final terms presented
Page 10: Deal closed or continued relationship maintained
```

### Scene Type 4: After-Sales Support (售后跟进)

```
Structure: 6 pages
Page 1: Issue raised by customer
Page 2: Support team investigating
Page 3: Solution identified
Page 4: Implementation / resolution
Page 5: Verification, customer satisfied
Page 6: Relationship strengthened, upsell opportunity
```

## Quality Markers

- [ ] Each script beat has clear business objective
- [ ] Dialogue advances the relationship/sale, not just information
- [ ] Visual directions are specific enough for image generation
- [ ] Character voices are distinguishable
- [ ] Scene tension rises and resolves satisfyingly
- [ ] Final panel includes clear call-to-action or next step
- [ ] Business context is accurate to the depicted industry/role
