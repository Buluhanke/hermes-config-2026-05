# 1688 Supplier Cooperation Story Guide

Create narrative comics about supplier relationships discovered, verified, and built through the 1688 (Alibaba CN) platform — from first inquiry to long-term partnership graduation.

## Content Type Profile

| Attribute | Value |
|-----------|-------|
| Triggers | 1688供应商故事、1688找厂、阿里采购、1688合作、工厂+买家故事、旺旺沟通、实力卖家 |
| Art Style | manga (default), ligne-claire |
| Tone | warm (default), dramatic, neutral |
| Layout | concept-story (default), standard, cinematic |
| Aspect | 3:4 (portrait) |
| Page Count | 8-16 pages |

## How This Differs from the Generic Supplier Story Guide

The base `supplier-story-guide.md` covers supplier stories in general. This guide adds 1688-specific platform mechanics, verification signals, and the unique journey from online discovery to offline partnership graduation.

| Element | Generic Supplier Story | 1688 Supplier Story |
|---------|------------------------|---------------------|
| Discovery | Referral, trade show, cold call | 1688 search, 实力卖家标签, 今日头条推荐 |
| Initial contact | Email, phone, in-person | 旺旺/阿里旺旺 chat first |
| Verification | Factory visit, third-party audit | 1688验厂报告, 诚信通认证, 实地认证, 工厂图册 |
| Trust signals | Sample order, small trial | 信用保障, 交易勋章, 回头率 |
| Payment | Wire, L/C | 支付宝/信用保障服务, 账期 |
| Relationship graduation | Face-to-face visits | 加微信/QQ, 线下拜访, 专属对接 |

## 1688 Platform Story Arcs

### Arc 1: The Discerning Buyer (挑剔采购商型)

```
Story Arc: Buyer searches 1688 → Filters by 实力卖家/诚信通 →
          Finds factory → 旺旺 inquiry → Sample order →
          Quality validates → Repeat orders → Vow to skip 1688

5-Stage Structure:
Stage 1 (Opening): Buyer burned by unreliable supplier, needs stable source
Stage 2 (Discovery): 1688 search with strict filters, factory catches eye
Stage 3 (Verification): Studies 工厂图册, 验厂报告, reviews, 交易记录
Stage 4 (Test): Sample order placed — tension around quality
Stage 5 (Trust): Sample passes, first container order, "skip the platform" moment
```

### Arc 2: The Factory's Digital Pivot (工厂数字化转型型)

```
Story Arc: Old factory relying on 线下老客户 → Joins 1688 →
          Struggles with线上运营 → Professional product photos +
          旺旺话术培训 → First线上询盘 → Becomes 实力卖家 →
          New revenue stream established

5-Stage Structure:
Stage 1 (Opening): Factory owner comfortable with traditional model
Stage 2 (Challenge): Old clients shrinking, needs new channels
Stage 3 (Learning): 1688 platform onboarding, professionalization
Stage 4 (First Contact): First旺旺 inquiry, nervous but excited
Stage 5 (Growth): Order volume grows, hires dedicated运营, skip-1688 clients
```

### Arc 3: The Urgent Crisis (紧急补货型)

```
Story Arc: Buyer gets urgent retail order → Normal lead time impossible →
          1688搜索 → Finds factory with fast反应 → 旺旺沟通 →
          Factory mobilizes → Order fulfilled → Becomes strategic partner

5-Stage Structure:
Stage 1 (Opening): Buyer's stable but slow supplier can't handle urgent need
Stage 2 (Crisis): Massive order lands, 7-day lead time required
Stage 3 (Search): 1688 search with "快速发货" filter, contacts 5 factories
Stage 4 (Response): Only one factory responds in 2 hours with方案
Stage 5 (Bond): Order delivered on time, buyer + factory become partners
```

### Arc 4: The Cross-Border Bridge (跨境采购型)

```
Story Arc: International buyer discovers 1688 → Translation tools used →
          Negotiates with basic Chinese → Factory patient, helps bridge →
          Cultural difference becomes strength → Long-term cross-border partnership

5-Stage Structure:
Stage 1 (Opening): International buyer needs China manufacturing, no connections
Stage 2 (Discovery): 1688 CN site (browser translated), finds competitive prices
Stage 3 (Barrier): Communication hurdles — language, cultural, payment
Stage 4 (Bridge): Factory uses simple English + photo updates + video calls
Stage 5 (Partnership): Successful delivery, buyer returns, brings referrals
```

## Character Design for 1688 Stories

### Character Archetypes

| Role | Archetype | Visual Cues | 1688 Context |
|------|-----------|-------------|--------------|
| 采购商 (Buyer) | 电商卖家/贸易商/品牌方 | Laptop, phone, warehouse boxes, casual professional | Seated at desk, browsing 1688 |
| 供应商 (Supplier) | 工厂老板/贸易商 | Industrial setting, safety vest, calloused hands | 旺旺头像 + 工厂photo in background |
| 跟单员 (Merchandiser) | Factory sales rep | Professional attire, phone always in hand | 旺旺 chat bubbles |
| 验货员 (QC) | Third-party inspector | Clipboard, quality tools, neutral professional | Inspection checklist visual |

### Visual Differentiation

| Character Type | Visual Cues | Expression Arc |
|----------------|-------------|-----------------|
| 电商新人买家 | Bright casual wear, laptop, excited but uncertain | Curious → Skeptical → Relieved → Confident |
| 资深贸易商买家 | Quality business casual, confident posture | Evaluating → Impressed → Satisfied → Trusting |
| 工厂老板 | Industrial practical, weathered hands, honest face | Welcoming → Confident → Responsive → Proud |
| 1688运营型销售 | Modern factory, professional photo outfit | Approachable → Helpful → Follows up |

### Visual Pacing Guidelines

Show 1688 platform elements in context — don't create a "screenshot comic." The platform is the medium, not the subject.

| Page Type | Platform Element Focus | Character Focus |
|-----------|----------------------|----------------|
| Discovery pages | Show 1688 search/listing context | Buyer's searching posture |
| Contact pages | 旺旺 chat bubbles central | Factory owner's response expression |
| Verification pages | Factory homepage/browser mockup | Buyer studying details |
| Sample pages | No platform — focus on product | Both parties on product |
| Order pages | 1688 order confirmation visual | Celebration/handshake moment |
| Partnership pages | None (platform graduation) | Both side by side, future-looking |

## Dialogue Templates for 旺旺 Scenes

### First Contact Templates

```
[Buyer]: 老板你好，请问这个[产品名]可以定制logo吗？[emoji: 握手]
[Factory]: 您好！可以的，我们支持[定制方式]。请问您需要什么颜色和尺寸呢？
[Buyer]: [产品参数]大概什么价位？[emoji: 思考]
[Factory]: 您的量是多少？我们根据量来报价最准确
[Buyer]: 首批大概[X]件
[Factory]: 好的，首批[X]件含税含运费[X]元/件。给您寄样品可以吗？
```

### Follow-up Inquiry Templates

```
[Buyer]: 老板，上次寄的样品收到了，质量不错！
[Factory]: 太好了！您看怎么样？
[Buyer]: 不错，想下个[数量]的订单，最快什么时候能出货？
[Factory]: 现在生产排期大概[X]天，加急的话可以[X]天
[Buyer]: 好的，那就按这个交期，麻烦您发个合同过来
```

### Problem Resolution Templates

```
[Buyer]: 老板，这批货收到有部分颜色不对，什么情况？
[Factory]: 非常抱歉！是我们的问题，给您补发[X]件可以吗？另外每件减[X]元
[Buyer]: 那补发的运费算谁的？
[Factory]: 算我们的，抱歉给您添麻烦了
[Buyer]: 好吧，下次注意啊
[Factory]: 一定一定！品控这边我们会加强，感谢您的理解
```

## Quality Markers

- [ ] 1688 platform elements are integrated naturally (not forced screenshots)
- [ ] Story arc follows the 1688 journey: discovery → verification → contact → sample → first order → partnership graduation
- [ ] Both buyer and supplier characters are sympathetic and humanized
- [ ] Platform verification signals (诚信通, 实地认证, 交易勋章) appear at natural story points
- [ ] 旺旺 dialogue feels authentic — short messages, emoji use, practical tone
- [ ] Platform graduation (direct contact, skip 1688) marks the relationship milestone
- [ ] Final page shows mutual growth and future-looking partnership
- [ ] Story could be used by factories for1688 supplier marketing or buyer onboarding education
- [ ] Chinese text uses full-width punctuation
