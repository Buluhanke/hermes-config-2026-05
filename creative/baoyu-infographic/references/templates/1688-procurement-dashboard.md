# 1688 Procurement Data Visualization

Dashboard template for 1688 (Alibaba.cn) procurement data visualization.

## Structure

- Header: procurement overview with key metrics
- KPI cards row: spend, orders, suppliers, avg lead time
- Supplier performance section
- Price trend section
- Category breakdown section
- Action items / alerts section

## Best For

- Monthly/quarterly procurement reviews
- Supplier performance reports
- Spend analysis dashboards
- 1688 platform data presentations

## Visual Elements

- KPI cards with big numbers and trend indicators
- Bar charts for category breakdown
- Line charts for price trends
- Supplier comparison table
- Status badges (green/yellow/red)

## Text Placement

- Title at top with date range
- KPI values prominent in cards
- Section headers above each module
- Labels and units clearly shown
- Source attribution at bottom

## Recommended Pairings

- `dashboard` + `corporate-memphis`: Business procurement reviews
- `dashboard` + `morandi-journal`: Lifestyle-friendly procurement reports
- `dashboard` + `pop-laboratory`: Technical procurement analysis
