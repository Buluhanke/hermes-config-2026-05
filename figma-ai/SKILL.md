# Figma AI

## When to Use
使用Figma进行UI/UX设计时，需要快速生成、编辑或优化设计稿。适合设计师提升工作效率。

## Core Features
- **Magical Edit**：AI驱动的局部编辑，选中元素自然语言修改
- **Auto Layout优化**：AI建议最优Auto Layout配置
- **设计系统生成**：从草图生成完整设计系统
- **文本生成**：AI辅助撰写UI文案
- **图片生成**：文生图填充设计

## Quick Start
```bash
# Figma内直接使用
# 1. 选中元素
# 2. 右键 → Magical Edit
# 3. 输入自然语言指令

# 桌面插件
# 工具栏 → 插件 → Figma AI
```

## Pitfalls
- 需要Figma Pro/Organization订阅
- Magical Edit偶有理解偏差
- Auto Layout建议需手动调整
- 生成内容版权归属需注意
