# Deep Research

系统性研究流程，输出结构化报告。

## 研究问题澄清
- 核心问题是什么？
- 需要什么粒度的信息？
- 有无特定角度需要优先覆盖？
- 研究的目的是什么？

## 研究流程

### 1. 拆解主题维度
将主题分解为子话题/维度，列出需要回答的核心问题。

### 2. 多源信息收集
- 优先搜索一手来源（官方文档、数据报告、论文）
- 交叉验证多个来源
- 注意信息发布时间和时效性
- 评估来源可信度

### 3. 整合发现
- 识别规律和主题
- 标注共识和分歧点
- 提炼关键洞察
- 连接关联信息

### 4. 记录来源
- 使用编号引用 [1][2]
- 末尾列出完整引用
- 标注不确定或争议内容

## 输出格式

\`\`\`markdown
## 执行摘要
[2-3句话概括核心发现]

## 关键发现
- **[发现1]**：[简述] [来源编号]
- **[发现2]**：[简述] [来源编号]
- **[发现3]**：[简述] [来源编号]

[深度分析，含引用]

## 多AI并行研究模式

当用户有多个模型（MiniMax/deepseek/Claude/Gemini等）且需要跨平台讨论收敛时，使用`delegate_task`并行分发同一份上下文：

```python
delegate_task(tasks=[
    {"goal": "把内容转发给ChatGPT/Claude，给出建议", "role": "leaf"},
    {"goal": "把内容转发给DeepSeek，给出建议", "role": "leaf"},
    {"goal": "把内容转发给智谱清言GLM，给出建议", "role": "leaf"},
], toolsets=["web"])
```

**触发条件**：用户说"发给X和Y讨论"、"多平台验证"、"让几个AI一起想"。

**关键约束**：
- `max_concurrent_children`默认3，超过需调高config
- 等待全部完成后汇总各方建议，去重+合并
- 子agent必须明确"中文回复简短精要"，避免各平台风格不一致

**输出格式**：汇总表格（平台 | 核心建议 | 差异点）

## 来源可信度评级
- 同行评审期刊/官方数据报告 → ★★★★
- 权威媒体/专业机构 → ★★★
- 专家评论/行业报告 → ★★
- 一般网站/论坛 → ★（需独立验证）

## 示例
**用户请求：** "研究一下义乌跨境电商的政策环境"

**研究步骤：**
1. 搜索义乌跨境电商政策、海关政策、综试区政策
2. 查找商务部/海关总署/浙江省官方文件
3. 查找行业分析报告（雨果网、亿邦动力等）
4. 整理政策要点、优惠条件、准入门槛
5. 标注政策时效性和潜在风险
