# 产品调研方法论

## 准确度检查清单（每次必查）

在给出产品推荐前，逐项确认：
- [ ] 这个价格是"起"还是实际配置的价格？
- [ ] 这个 CPU 型号是目标型号还是混淆的其他型号？
- [ ] 是准系统还是整机？买家到手还要花多少钱配齐？
- [ ] 设备体积/噪音适不适合家用的实际场景？
- [ ] 给出了购买链接吗？

## 常见坑点

### 价格坑
- 搜索结果里的"¥399 起"是最低配 SKU 的噱头，不代表你看的那款的价格
- 点进商品页面，看 SKU 选项里实际配置对应的价格
- 整机 vs 准系统价格不能直接比较

### 配置坑
- N100 ≠ N150 ≠ N2940 ≠ J4125 — 是不同的 CPU
- 商品标题写"N100"的也要核对套餐里实际发的是哪个型号
- 缓存的旧价格可能已过时，以搜索结果里的为准

### 场景坑
- 用户说"家用" → 不要推荐 bulky 工控机
- 用户说"小型" → 体积和噪音跟网口数量一样重要
- 纯路由用途：高端 CPU 性能过剩，中端足够

## 搜索策略

- 拼多多往往比淘宝更便宜，但需要 APP 内打开
- B站视频评测里的价格是博主购入价，可信度高
- 加 `site:taobao.com` 筛选具体商品
- 用「准系统」「裸机」过滤套餐混淆
- 找到低价后去视频平台验证实际购入价

## 输出格式

给出产品推荐时，必须包含：
1. 具体型号 + 配置
2. 实际成交价（不是"起"价）
3. 是否含内存硬盘电源
4. 适合的使用场景
5. 购买链接
