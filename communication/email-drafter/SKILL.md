# Email Drafter

专业商务邮件起草框架。

## 邮件结构
1. **主题**：清晰、具体、可操作
2. **称呼**：对应关系（老板/平级/供应商/客户）
3. **开场**：背景和目的
4. **正文**：核心要点（通常2-3点）
5. **行动号召**：你需要对方做什么
6. **结尾**：专业落款

## 语气场景

| 场景 | 语气 | 场景举例 |
|------|------|---------|
| 正式 | 尊称+完整句式 | 首次联系、投诉、合同 |
| 专业 | 清晰+礼貌 | 标准商务沟通 |
| 友好 | 轻松+自然 | 长期合作方、内部沟通 |
| 直接 | 简洁+重点 | 紧急事项、催单 |

## 1688场景邮件要点
- 1688 供应商通常回复较快，邮件要简短
- 开头可提"1688后台看到贵司"
- 结尾留手机号方便对方加微信
- 议价时给出目标价格和量，不要只说"便宜点"
- 从不微信/QQ转账给供应商，走支付宝

## 邮件签名格式
```
[姓名]
[公司名] 采购部 / 销售部 / 运营部
手机：[号码] 微信/WhatsApp同号
邮箱：[邮箱]
地址：[公司地址]
```

## 1688场景核心原则
1. 回复要及时：供应商通常24小时内回复，超过2天可打电话
2. 留手机号：结尾留手机/微信，方便对方快速联系
3. 不走私下转账：坚持支付宝/对公，不微信不QQ不打私人卡
4. 议价要给数字：别说"便宜点"，给目标价+量才有诚意
5. 保留聊天记录：1688后台记录可作纠纷证据
6. 验货再签收：有问题当场拍照留证
