# 1688 商务邮件模板

## 供应商开发邮件（首次联系）
```
主题：[公司名] - 包装材料长期采购合作咨询

您好，

我们是义乌市迅龙贸易有限公司，长期在1688采购纸箱等包装材料。

看到贵司的产品比较符合我们的需求，想建立长期合作。

我们主要采购：
- 纸箱（各种规格）
- 气泡膜/珍珠棉
- 胶带/打包带

稳定月采购量[X]万+，希望找质量稳定、价格有优势的供应商。

方便的话加我微信[手机]详聊，或者直接邮件报价都行。

谢谢！
迅龙贸易
[联系人] [手机]
```

## 询价邮件模板
```
主题：询价 - [产品名称] [规格参数] [数量]

您好，

我是[公司名]采购，想询一下贵司[产品]的价格。

需求详情：
- 产品：[名称+规格]
- 数量：[X件]
- 交期：[期望日期]
- 其他要求：[特殊工艺/包装等]

麻烦报一下含税含运费价格，以及可执行的交期。

谢谢！
[姓名]
[公司]
[联系方式]
```

## 催单邮件
```
主题：订单[订单号]进度确认 - 急

您好，

之前下单的[产品]，合同约定[日期]交货，想确认下目前生产进度。

我们的交期比较紧，麻烦帮忙确认：
1. 当前生产到哪一步了？
2. 是否能按期交货？
3. 如果有风险，最晚能什么时候发？

谢谢，[联系人]
```

## 议价邮件
```
主题：关于[产品]价格的商量

您好，

感谢之前的报价。我们看了其他供应商的价格，希望能在[目标价格]左右成交。

我们的订单量稳定[数量/月]，长期合作的话希望价格能再谈谈。

麻烦评估一下，有空间的话我们尽快下单。

谢谢！
[姓名]
```

## 1688 场景要点
- 1688 供应商通常回复较快，邮件要简短
- 开头可提"1688后台看到贵司"
- 结尾留手机号方便对方加微信
- 议价时给出目标价格和量，不要只说"便宜点"
- 从不微信/QQ转账给供应商，走支付宝
