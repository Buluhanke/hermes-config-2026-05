# 1688 商务邮件模板大全

## 邮件通用结构
```
1. 主题：清晰、具体、可操作（含关键信息）
2. 称呼：敬称+对方身份
3. 开头：背景和目的（1-2句）
4. 正文：核心要点（通常2-3点，每点简短）
5. 行动号召：明确你要对方做什么
6. 结尾：感谢+落款+联系方式
```

## 1688场景注意事项

1. **回复要及时**：1688供应商通常24小时内回复，超过2天不回复可以打电话
2. **留手机号**：结尾留手机/微信，方便对方快速联系
3. **不走私下转账**：坚持走支付宝/对公，不微信不QQ不打私人卡
4. **议价要给数字**：别说"便宜点"，给目标价+量，才有诚意
5. **保留聊天记录**：1688后台聊天记录可作为纠纷证据
6. **验货再签收**：收货时尽量验货，有问题当场拍照留证
7. **开票要提前说**：下单前确认能否开票、开几点的，避免事后纠纷
