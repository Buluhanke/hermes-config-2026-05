# 知识管理体系

持续积累和管理知识的完整skill。

## 核心内容

### 知识分类
1. 事实性知识：供应商信息、产品规格、价格区间
2. 流程性知识：1688采购流程、询价话术、议价策略
3. 经验性知识：踩坑案例、供应商偏好、时令规律
4. 元知识：如何学习知识、如何验证知识是否正确

### 知识来源优先级
1. 第一手：亲身经历/1688官方文档/开源项目源码
2. 第二手：GitHub issue/技术博客/行业报告
3. 第三手：AI总结/二手解读（谨慎对待）

### 知识入库标准
```
✓ 可以入库：
- 经过验证的真实经验
- 有据可查的事实
- 反复有效的策略

✗ 不入库：
- 未经证实的"最佳实践"
- 可能过期的一次性信息
- 纯理论没有实践机会的知识
```

### 知识整理流程
```
每日：记录新学到的东西（5分钟）
每周：复盘整理，去除冗余（30分钟）
每月：更新技能文档，删除过时内容
每季：审视知识体系，检查缺口
```

### RAG知识库实践
- ChromaDB做向量存储
- 分块策略：按主题/按章节/按长度（建议500字/块）
- 检索策略：混合检索（向量+关键词）
- 更新策略：增量更新，不重复重建

### 与记忆体系的分工
- hermes-memory-hpc：老板偏好、跨会话状态、情感记忆
- knowledge-management：事实性知识、流程、经验
- 两者互补，共同构成长期记忆
