# 1688 开放平台 AppKey 申请指南

## 结论

1688 开放平台 API **需要企业资质**，个人无法申请。

## 申请条件

| 要求 | 说明 |
|------|------|
| 营业执照 | 必须是企业/公司，个体工商户可能也受限 |
| 1688 企业认证 | 公司已通过 1688 企业认证 |
| 企业支付宝/微信 | 需要绑定企业的支付账户 |
| 开发者账号注册 | 用企业信息在 open.1688.com 注册 |

## 申请流程（推测）

1. 访问 [open.1688.com](https://open.1688.com)
2. 用企业支付宝扫码登录（或企业账号登录）
3. 提交营业执照、企业信息认证
4. 创建应用，获取 AppKey + AppSecret
5. 调用 API 时签名鉴权

## 对 Hermes 的影响

当前 Hermes 的 1688 自动化方案：
- **CDP 拦截法**：已实现，无需 AppKey，可提取商品/供应商数据
- **API 方案**：需企业资质，当前不可用

如未来需要完整 API 能力（批量查询、自动议价、订单管理），需老板提供企业资质申请 AppKey。

## 替代方案

| 方案 | 成本 | 难度 |
|------|------|------|
| CDP 拦截（当前） | 免费 | 低 |
| 第三方数据平台 | ¥500+/月 | 低 |
| 企业认证后申请 AppKey | 免费 | 需企业资质 |
