## 安装顺序

```bash
source ~/.hermes/hermes-agent/venv/bin/activate

# 基础 ML 工具链
uv pip install torchvision transformers Pillow

# 物体检测
uv pip install ultralytics

# 背景去除
uv pip install rembg

# RMBG HuggingFace 依赖
uv pip install scikit-image
```

## 注意

所有包装到 hermes-agent venv (Python 3.11)，不是系统 Python 3.14。
通过 `source ~/.hermes/hermes-agent/venv/bin/activate` 激活后运行。
