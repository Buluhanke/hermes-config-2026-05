## Consensus: Q4_K_M + KV Quantization is Best

Three AI sites (DeepSeek, Grok, Doubao) independently agreed:

| Quant | Model Size | KV Cache (64K) | Peak Total | Verdict |
|-------|-----------|---------------|-----------|---------|
| **Q4_K_M** | ~4.9GB | ~3.8-4.2GB | ~8.6-9.3GB | ⭐ BEST |
| Q3_K_M | ~3.7GB | ~3.5-3.9GB | 7.2-7.9GB | Backup |
| Q4_0 | ~4.3GB | ~3.7-4.1GB | 8.1-8.8GB | Not recommended |
| **Q8_0** | ~8.5GB | ~5.0-5.5GB | **13.3-14.3GB** | ❌ Never |

Q4_K_M = ~3% accuracy loss, stable tool-calling. Q8_0 single-handedly eats 14GB → forces Swap.

## Environment Variables

⚠️ Do NOT add to `~/.zshrc` — it's protected by Hermes. Use `~/.ollama/ollama.env`:

```bash
# /Users/aimac/.ollama/ollama.env
OLLAMA_FLASH_ATTENTION=1
OLLAMA_NUM_THREAD=8
OLLAMA_CONTEXT_LENGTH=8192       # 8K not 64K — saves ~3-4GB KV cache
OLLAMA_MAX_LOADED_MODELS=1
OLLAMA_NUM_PARALLEL=1
OLLAMA_KV_CACHE_TYPE=q8_0
OLLAMA_KEEP_ALIVE=0             # ⭐ KEY: unload model after inference, idle=35MB
```

> ⚠️ **KEEP_ALIVE=0 is critical.** Without it, model stays in memory at 5.7GB even when idle.
> Context length: Use 8192 not 65536. 64K context adds ~3-4GB KV cache overhead.

Restart ollama to load: `launchctl kickstart -k gui/$(id -u)/homebrew.mxcl.ollama && ollama serve &`

## Startup Script

**`~/.hermes/scripts/ollama_hermes.sh`** — 一键启动脚本（含内存门卫）:
- Checks `vm_stat` free+inactive+speculative pages
- Converts to GB: `pages × 16384 / 1024^3`
- **Loads model only if free memory > 7GB**, otherwise skips and logs "跳过模型加载"
- Service stays up regardless; model loads on-demand via `ollama run hermes-8b`

### ⚠️ vm_stat awk parsing bug

`vm_stat` output has trailing dots on numbers (e.g., `407763.`). `$3` in awk will capture the string with the dot, and `+0` coerces it to `407763` — which *happens* to work because `407763.+0 = 407763`. BUT for the **inactive** and **speculative** fields (last column), `$NF` may be `4980.` and `gsub(/\./,"",$NF)` is needed before numeric conversion.

**Correct awk:**
```bash
# Extract last field (speculative), strip dot, convert to GB
gsub(/\./,"",$NF)
free_total=$(echo "scale=2; ($free + $inactive + $spec_pages) * 16384 / 1024^3" | bc)
```

**Wrong (subtle failure mode):**
```bash
free='$3'+0   # Works for Pages free, but $3 may not be the right field
# depending on vm_stat output format on different macOS versions
```
