# dl-system

FlashKDA decode kernel: ~7·D² FLOPs, ~8·D² bytes memory traffic (FP32 recurrent state dominates). Prefill: 12·C³ + 8·C²·D + 6·C·D² FLOPs, (8·C² + 22·C·D) bytes. Chunk size C, hidden dim D. KDA output normalized per head, output forget gate implemented as linear transformation (not low-rank projection as in Kimi Linear). Short convolution on QKV captures local token dependencies; L2 norm on Q and K stabilizes eigenvector. Shared expert count and hybrid linear attention ratio from Kimi Linear paper.
