# 云视觉选型 —— 看图任务决策表

用户发图片要「看懂」时（不是 GUI 找坐标），按下面顺序决策。榜单分数只是候选依据，选型时必须实测当前凭据能否调用。

## 路由优先于选型

1. **原生像素优先**：主模型支持 image input 时，让像素直达主模型。保持 `auxiliary.vision.model` 为空；任何显式 aux 模型/后端都会把原生视觉切成「aux 先用文字描述图片」，细节和符号会丢。
2. **描述链只在主模型看不了图时用**：aux 后端自己必须能看图，fallback 每一项都要能看图。
3. 验证方式是看实际路由（`decide_image_input_mode` 返回 `native`），不是看配置文件写了什么。

## 按任务选模型（数字为选型时榜单示例，会过时）

| 任务 | 优先候选 | 理由 |
|---|---|---|
| 通用图像问答、图表、OCR 综合 | LMArena Vision 头部（Claude Fable 5 档）；成本敏感用 Gemini Flash 档 | 人类盲测偏好；OCR/图表分榜头部自成一档 |
| 客观计数、检测、定位、推理 | Roboflow Vision Evals 头部（Gemini 4 Neon ~91.0%，Carbon ~89.4%，GPT-6.2 Sol ~90.3%） | 同图同任务对 ground truth 打分，非投票 |
| 复杂图文推理 | MMMU-Pro 头部（GPT-6.2 Astra ~89.5） | 学科级图表/文档推理 |
| 文档结构化、表格、公式 | 专用 parser（Qianfan-OCR / PaddleOCR-VL / TeleOCR / OCRia-1 档） | 通用 VLM 在合并单元格、图表数值还原上明显落后；图表要返回数据表而非文字描述 |
| 开源可自托管 | GLM-5.3-Flash 档（MIT）或 Qwen 开源 VL 档 | 权重可审计、无外发数据 |

## 精度铁律

- **小字先裁再送**：服务端会在模型看到图之前缩放，大图里几十像素的目标会消失。先定位区域、按原图坐标裁切（`vision_analyze` 的 `region` 参数），再送裁图；不要指望放大整图补回来。
- **精确符号以像素为准**：OCR 交叉核对时常见 `×→X`、`¥→￥`、空格丢失；要原样转录尺寸/单价/编号，用原生视觉结果，OCR 只做一致性校验。
- **可用性必须实测**：Catalog 列出模型 ≠ 能调用。带真实图片 POST 一次，看是否返回正文；region 403、余额 404、429 配额耗尽都按不可用处理，立刻换 fallback。
- **榜单不可直接比较**：人类投票榜、客观任务榜、文档解析榜的样本和指标不同；同一模型在不同榜名次可以差很远，按任务选对应榜。
