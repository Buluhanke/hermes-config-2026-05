# ClawGUI — Unified Framework for GUI Agents (ZJU-REAL)

- **arXiv**: 2604.11784 (Apr 2026)
- **GitHub**: github.com/ZJU-REAL/ClawGUI
- **Project**: zju-real.github.io/ClawGUI-Page/

## Three Components

### 1. ClawGUI-RL
- First open-source RL infrastructure for GUI agents
- Combines **GiGPO** with process reward model for dense step-level supervision
- Validated on parallel virtual environments + real physical devices

### 2. ClawGUI-Eval
- Standardized eval across 6 benchmarks × 11+ models
- 95.8% reproduction rate with official baselines

### 3. ClawGUI-Agent
- Deploys to Android, HarmonyOS, and iOS via 12+ chat platforms
- Hybrid CLI-GUI control + persistent personalized memory
