# Qwen-VLA（2026-05-28, arXiv 2605.30280）

## 概述
Qwen 团队发布的统一 Vision-Language-Action（VLA）基础模型。将视觉感知、语言理解和连续动作生成统一到一个框架中。

## 核心架构
- **视觉-语言骨干**：Qwen3.5-4B
- **动作解码器**：1.15B DiT（Diffusion Transformer）flow-matching decoder
- **总参数量**：~5.15B
- **设计目标**：将操控、导航、轨迹预测纳入共享动作-轨迹预测空间

## 关键亮点
- 🏆 **一个通用模型打败专家**：单一模型匹配或超越在每个 benchmark 上独立微调的专家
- 🔗 **统一框架**：操控、导航、第一人称动作建模、轨迹预测共享一个动作-轨迹预测空间
- 🤖 **Embodiment-Aware Prompt**：一套权重服务多个平台，仅修改文本 prompt 即可切换形态
- 📈 **渐进式训练**：大规模动作预训练 → 多模态继续预训练 → SFT → RL

## 核心设计概念
1. **统一动作-轨迹预测框架**：将操控（连续动作）、导航（离散路径）和轨迹预测建模为共享空间
2. **DiT Flow-Matching**: 连续动作生成通过扩散 transformer 解码，而非直接 token 预测
3. **Embodiment-Aware Prompt**: 不同机器人的规格说明书以文本形式嵌入，模型自动适配

## 对 Hermes 的意义
- VLA 架构（视觉编码器 + LLM + 动作解码器）≈ Hermes 需要的 GUI agent 架构
- DiT action decoder 概念可映射到 GUI 动作预测（坐标 click/type/scroll）
- Qwen3.5-4B（~4GB）+ 1.15B 解码器（~1.5GB）= ~5.5GB，可能超出 M4 24GB 的 Ollama 可用内存（当前 qwen3-vl:2b 1.76GB 稳定）
- **关键差距**：当前 Qwen-VLA 聚焦机器人领域（连续关节控制），不直接支持 GUI 动作（离散 click/type/scroll）
