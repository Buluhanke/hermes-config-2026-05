# GAL — GUI Agent Autonomy Levels (arXiv 2602.11514)

## Basic Info
- **Title**: How Smart Is Your GUI Agent? A Framework for the Future of Software Interaction
- **Authors**: Sidong Feng, Chunyang Chen
- **Date**: Feb 12, 2026
- **Source**: arxiv.org/abs/2602.11514
- **Subjects**: cs.SE, cs.AI, cs.CV, cs.HC

## Core Contribution
**GUI Agent Autonomy Levels (GAL)** — a six-level framework that makes agent autonomy explicit and helps benchmark progress toward trustworthy software interaction.

## Key Insight
GUI agents are described with radically different degrees of autonomy, obscuring capability, responsibility and risk. GAL provides conceptual clarity by defining levels from fully human-controlled to fully autonomous.

## Hermes Relevance
- Current Hermes auto-execute (DRY_RUN) is effectively at Level 1-2 (read-only + approval-gated)
- GAL framework can structure the DRY_RUN=False transition roadmap
- Provides shared vocabulary for discussing autonomy progression
