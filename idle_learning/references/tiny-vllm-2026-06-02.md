## 技术栈

- **语言**：C++ + CUDA
- **所有计算**：CUDA kernels（无 PyTorch 依赖）
- **模型格式**：Safetensors（Llama 3.2 1B Instruct 实测加载）

## 学习价值

- **CUDA kernel 工程**：从零手写 attention、embedding、softmax kernel，理解底层原理
- **推理引擎原理**：PagedAttention、KV cache、continuous batching 的具体实现
- **Mac M4 限制**：CUDA 需 NVIDIA GPU，Mac M4 无法直接运行；但 kernel 源码可作为学习素材
- **Memory Bandwidth 瓶颈**：Decode 算术强度低（FP16 ~1 FLOP/byte），理解为何 LLM 推理受 memory bandwidth 限制而非 FLOPS

## 相关项目

- **nano-vLLM**：~1.2k 行，Pure Python + Triton，易修改（HN 文章）
- **vLLM vs Ollama benchmark**：markaicode.com/benchmarks/cuda-throughput-benchmark/
- **Kog AI Inference Engine**：3,000 tokens/s per request on 8× AMD MI300X（参考基准）

## 局限性

- CUDA only，无法直接在 Mac M4（ROCm）上运行
- 主要面向学习，不建议直接用于生产
- 当前仅支持 Llama 3.2 1B（测试模型）
