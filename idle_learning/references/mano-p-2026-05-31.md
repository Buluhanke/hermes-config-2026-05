# Mano-P — Apple Silicon 本地 GUI-VLA Agent

**发现日期**：2026-05-31
**来源**：Mininglamp AI, GitHub: Mininglamp-AI/Mano-P

## 概述

Mano-P 是首个完全本地运行的 GUI-VLA (Vision-Language-Action) agent，专为 Apple Silicon 边缘设备设计。"Mano"在西班牙语中意为"手"，"P"代表 Private — 强调隐私优先。

**GitHub**: https://github.com/Mininglamp-AI/Mano-P
**HuggingFace**: https://huggingface.co/Mininglamp-AI/Mano-P
**ModelScope**: 同名

## 核心规格

| 指标 | 数值 |
|------|------|
| 参数量 | 4B |
| 内存占用（4-bit量化） | ~4GB |
| M4 Pro 吞吐 | ~40 tokens/s |
| OSWorld（specialized模型） | **#1，58.2%** |
| CUA benchmark | 匹配更大云模型准确率 |

**M4 适配性**：M4 Pro 上 4-bit 量化版 40 tokens/s，内存仅 4GB。**16GB MacBook Air 可流畅运行**。

## 架构

- **三阶段训练**：SFT → Offline RL → Online RL
- **Think-Act-Verify reasoning loop**
- **训练数据**：60,000 GUI trajectories，300万+ actions
- 支持 macOS 截图 → 视觉理解 → 动作执行全链路

## benchmark 对比

| 模型 | OSWorld | 备注 |
|------|---------|------|
| Claude Computer Use | 72.1% | 需要云端 API |
| **Mano-P 4B** | **58.2%** | 完全本地 |
| smolvlm2-agentic-gui | 61.71% (ScreenSpot-V2) | 不同 benchmark 不可直接比 |

**结论**：Mano-P 在 specialized 模型中 OSWorld 第一，但比 Claude 仍有差距。完全本地运行，隐私无忧。

## 配套：Cider 推理加速 SDK

**GitHub**: https://github.com/Mininglamp-AI/cider

解决 MLX 原生只有 W4A16 量化的限制，实现真正的 W8A8（weights INT8 + activations INT8）。

**M5 Pro 性能**：
- W8A8 (with Cider): 相比 W4A16 有显著提升
- Qwen3-VL-2B chunked prefill: 大幅加速
