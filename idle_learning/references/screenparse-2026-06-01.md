# ScreenParse + ScreenVLM — Complete Screen Parsing for GUI Understanding

**Paper**: arXiv 2602.14276 | **Published**: 15 Feb 2026 (v2: 1 May 2026) | **Venue**: ICML 2026

**Title**: ScreenParse: Moving Beyond Sparse Grounding with Complete Screen Parsing Supervision

**Authors**: A. Said Gurbuz, Sunghwan Hong, Ahmed Nassar, Marc Pollefeys, Peter Staar

## Core Contributions

### 1. ScreenParse Dataset (v1 / v2)
- **ScreenParse v1** (Feb 2026): 771K web screenshots, 21M UI elements (boxes, 55-class, text)
- **ScreenParse v2** (May 2026): **1,447,100 screenshots, 25,575,213 elements**, leaf-element filtering
- Generated by **Webshot**: automated pipeline renders URLs → extracts annotations → VLM relabeling → quality filtering
- 55 UI element classes across web screenshots

### 2. ScreenVLM — 316M Parameter VLM
- Decodes compact **ScreenTag** markup representation
- Structure-aware loss that upweights structure-critical tokens
- **0.592 PageIoU** on ScreenParse (vs 0.294 for much larger 8B+ foundation VLMs)
- 4x faster than 2B VLMs — designed for low-latency, on-device deployment

### 3. ScreenParser — YOLO11-Large (NEW)
- HuggingFace: `docling-project/ScreenParser` (Apache 2.0)
- IBM Research - ETH Zurich collaboration
- Fine-tuned at 1280px on ScreenParse v2
- 55 UI element classes
- Usage: `YOLO("docling-project/ScreenParser")`, imgsz=1280
- ~millisecond inference (ultralytics + Metal on M4)
- Package: ultralytics v8.4.57 already installed (hermes venv)

### 4. Key Finding: Dense Screen Supervision Transfers
- Fine-tuning foundation VLMs on ScreenParse **consistently improves** grounding performance
- Dense screen supervision provides **transferable structural priors** for UI understanding
