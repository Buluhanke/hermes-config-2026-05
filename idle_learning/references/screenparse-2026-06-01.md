# ScreenParse + ScreenVLM — Complete Screen Parsing for GUI Understanding

**Paper**: arXiv 2602.14276 | **Published**: 15 Feb 2026 (v2: 1 May 2026) | **Venue**: ICML 2026

**Title**: ScreenParse: Moving Beyond Sparse Grounding with Complete Screen Parsing Supervision

**Authors**: A. Said Gurbuz, Sunghwan Hong, Ahmed Nassar, Marc Pollefeys, Peter Staar

## Core Contributions

### 1. ScreenParse Dataset
- **771K** web screenshots with dense annotations
- **21M** UI elements with: bounding boxes, 55-class element types, text content
- Generated by **Webshot**: automated pipeline that renders diverse URLs → extracts annotations → VLM-based relabeling → quality filtering

### 2. ScreenVLM — 316M Parameter VLM
- Decodes compact **ScreenTag** markup representation
- Structure-aware loss that upweights structure-critical tokens
- **0.592 PageIoU** on ScreenParse (vs 0.294 for much larger foundation VLMs)
- Designed for low-latency, on-device deployment

### 3. Key Finding: Dense Screen Supervision Transfers
- Fine-tuning foundation VLMs on ScreenParse **consistently improves** grounding performance
- Dense screen supervision provides **transferable structural priors** for UI understanding
