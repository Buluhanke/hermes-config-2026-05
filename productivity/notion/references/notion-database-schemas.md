# Notion 数据库 Schema 参考

## 采购订单数据库 (Procurement)

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| 名称 | title | 采购品名 | "紧急纸箱采购-深圳仓" |
| 供应商 | select | 供应商名称 | "供应商A" |
| 产品类别 | select | 产品分类 | "纸箱" |
| 订单状态 | select | 6种状态 | "待询价" |
| 采购数量 | number | 数量 | 500 |
| 单位 | select | 计量单位 | "个" |
| 单价 | number | 单价(元) | 2.50 |
| 总价 | formula | 自动计算 | 1250.00 |
| 询价日期 | date | 发起询价时间 | 2026-05-17 |
| 预计到货 | date | 预计到货时间 | 2026-05-25 |
| 实际到货 | date | 实际到货时间 | 2026-05-24 |
| 1688订单号 | rich_text | 1688订单号 | "TB123456" |
| 备注 | rich_text | 备注信息 | "" |
| 紧急程度 | select | 4级紧急度 | "高" |
| 老板审批 | checkbox | 审批状态 | false |

### 状态流转

```
潜在 → 待询价 → 询价中 → 待下单 → 已下单 → 已到货 → 已完成
                                    ↓
                              老板审批拒绝 → 重新询价
```

## 供应商跟踪数据库 (Supplier)

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| 供应商名称 | title | 供应商名称 | "深圳纸箱厂" |
| 联系人 | rich_text | 联系人姓名 | "张经理" |
| 电话 | phone_number | 联系电话 | "+86-138-0000-0000" |
| 微信 | rich_text | 微信号 | "zhang8388" |
| 1688店铺 | url | 1688店铺链接 | "https://shop123456.1688.com" |
| 主营产品 | multi_select | 产品分类 | ["纸箱", "气泡膜"] |
| 合作状态 | select | 4种状态 | "合作中" |
| 评分 | number | 1-5分 | 4 |
| 平均交期(天) | number | 平均交期 | 7 |
| 最低起订量 | rich_text | MOQ | "500个起" |
| 账期 | select | 付款账期 | "月结" |
| 创建日期 | date | 首次添加日期 | 2026-01-01 |
| 最近联系 | date | 最近联系日期 | 2026-05-10 |
| 备注 | rich_text | 其他备注 | "" |

### 合作状态流转

```
潜在 → 合作中 → 暂停 → 淘汰
         ↓
       合作中（持续合作）
```

## 老板仪表盘数据库 (Dashboard)

建议直接使用普通页面+嵌入视图，不建数据库。
如需数据库，参考采购订单库结构精简版。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 指标名称 | title | "紧急订单数" |
| 当前值 | number | 3 |
| 变化趋势 | select | "上升/下降/持平" |
| 更新时间 | date | 2026-05-17 |

## 1688订单号格式参考

1688订单号通常为数字，如 `2354867293018291000`
建议在 Notion 中存为 rich_text，保留完整精度。
