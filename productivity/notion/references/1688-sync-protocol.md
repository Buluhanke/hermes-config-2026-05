# 1688 订单同步协议

## 同步方式

1688 无官方公开 API，推荐两种同步方式：

### 方式1：CSV导出（推荐）

1. 登录 1688 → 我的订单 → 批量导出
2. 保存为 `/tmp/1688-orders.csv`
3. 运行同步脚本

### 方式2：浏览器自动化

使用 Chrome DevTools Protocol 或 Playwright 登录1688自动抓取。

## CSV 格式要求

```csv
订单号,供应商,商品名称,数量,单价,总额,下单时间,物流状态
TB123456789,深圳纸箱厂,加厚纸箱100个,500,2.50,1250.00,2026-05-17,已发货
```

## 字段映射

| CSV列 | Notion字段 | 类型 |
|--------|-----------|------|
| 订单号 | 1688订单号 | rich_text |
| 供应商 | 供应商 | select（需提前在Notion建好供应商选项） |
| 商品名称 | 名称 | title |
| 数量 | 采购数量 | number |
| 总额 | 总价 | number |
| 下单时间 | 询价日期 | date |
| 物流状态 | 订单状态 | select |

## 状态映射规则

```bash
case "$status" in
  待付款)   notion_status="待询价" ;;
  待发货)   notion_status="待下单" ;;
  已发货)   notion_status="已下单" ;;
  运输中)   notion_status="已下单" ;;
  已签收)   notion_status="已到货" ;;
  已完成)   notion_status="已完成" ;;
  已取消)   notion_status="已取消" ;;
esac
```

## 供应商名称匹配

同步时需要将1688的供应商名称与Notion供应商数据库中的select选项匹配。
如遇新供应商，脚本会跳过并在日志中记录。

## 防重复同步

同一 1688订单号 只同步一次（基于 1688订单号 字段去重）。
建议在 Notion 中对 1688订单号 设置 unique 约束。
