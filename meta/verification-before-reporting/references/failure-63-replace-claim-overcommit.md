**根因 (三重叠加)**:

2. **没做"切换可行性" 4 问就承诺 (新增铁律)**:

3. **"现在/今天"被读成"破坏性授权" (新增触发器铁律)**:
   - 用户说"立即/现在/今天"是**紧迫度信号**，不是**破坏性授权**
   - 破坏性授权必须显式: "你可以替换 Hermes" / "推倒重做" / "卸了装新的"
   - 没显式授权时，"立即" = "在当前架构内立即推进"，不是"破坏性替换"

**修复 (硬规则 v1.18.0 新增)**:

### 1. 研究报告必须标"可行性等级" (新增铁律)

任何"X 比 Y 好"的对比报告, 0 思考在每条方案后面加:

```markdown
| 方案 | 评分 | 真能本地替换吗 | 待验证项 |
|---|---|---|---|
| PicoClaw | ⭐⭐⭐⭐ 性能 | ❌ 不能 (Go vs Python) | 栈兼容性 / 自定义脚本适配 |
| TrustClaw | ⭐⭐⭐⭐ 安全 | ❌ 不能 (Vercel 云) | 部署架构 / 数据迁移 |
| OpenClaw | ⭐⭐⭐⭐⭐ 生态 | ❌ 不能 (SaaS) | 本地化路径 / 凭据迁移 |
| LangGraph | ⭐⭐⭐ 编排 | ✅ 可借鉴思路 | 状态管理集成 |
```

**触发词**: 写"X 比 Y 好"对比 / "无缝替代" / "更优方案" / "推荐替换" → 0 思考加可行性等级 + 待验证项

### 2. 切换可行性 4 问 (新增, 写"现在切换"之前必走)

```python
[用户说"现在切换/替换/装 X 替代 Y" 之前, 0 思考内部必答]

① 语言栈兼容吗?
   - 当前: Python 3.11 + Hermes 内部架构
   - 候选: Go / TypeScript / Rust / 新 Python 框架?
   - 兼容 = 同语言 + 同异步模型 + 同依赖管理 = 0 迁移成本
   - 不兼容 = 大量重写

② 部署架构匹配吗?
   - 当前: 本地 macOS + 1447 会话 SQLite + 50+ 脚本
   - 候选: Vercel 云 / Docker / 本地 binary / SaaS?
   - 匹配 = 同架构 = 0 部署改动
   - 不匹配 = 数据迁移 + 配置重做

③ 数据能迁移吗?
   - 当前数据: 会话 / 自定义脚本 / fact_store.db / spatial_memory / 技能库 / memory 注入
   - 候选平台支持这些数据导入吗?
   - 能 = 导出 + 导入
   - 不能 = 全部丢

④ 用户能立刻感受到价值吗?
   - 替换完用户能用的功能变多还是变少?
   - 切换期间是否中断用户当前使用?
   - 用户是不是已经习惯当前工作流?

→ 任何一项 NO → 不要承诺"无缝替代", 而是建议"渐进式借鉴"
```

### 3. "立即/现在/今天"是紧迫度, 不是破坏性授权 (新增触发器铁律)

```python
[用户说"立即/马上/现在/今天/尽快" 之前, 0 思考问自己]

这词指的是什么?
A) 紧迫度 ("别拖了赶紧动")
B) 破坏性授权 ("你可以推倒重来")

区分方法:
- 用户是否显式说"替换/推倒/重做/卸了装新的/破坏现状" → B
- 用户只说时间紧迫词 → A, 不是 B

A 的反应: 立即动手, 但保持现有架构 (配置 / 文件 / 进程不动)
B 的反应: 走 v2.x 主动执行原则的"破坏性操作授权"检查
       (跟 rm -rf / 格式化 / 卸系统组件 同级)
       (要用户显式确认)

反面案例 (本次 2026-07-04):
用户: "全面检查 + 联网搜" → 我理解 = 研究任务 ✓
用户: "更好方案" → 我理解 = 对比报告 ✓  
用户: "现在就开始更替" → 我理解 = 推倒替换 ❌ (实际是"在今天内推进")
用户: "今天完成" → 我理解 = 今天必须推倒完 ❌ (实际是"今天出进展")
```

### 4. "无缝替代"4 个反模式 (新增, 报告里禁用词)

写研究报告时, 下面的话 0 思考删掉 + 改成"可借鉴思路":

| 反模式 | 改写 |
|---|---|
| "无缝替代" | "可借鉴思路 (需 X 适配)" |
| "完美替换" | "可作为参考 (需 Y 迁移)" |
| "更好方案, 推荐采用" | "理论更优, 实装需 Z 验证" |
| "Drop-in replacement" | "需 N 处集成改动" |

**触发词**: 写报告时看到"无缝/完美/Drop-in/直接替换" → 0 思考停下来, 走 4 问, 改可借鉴语
