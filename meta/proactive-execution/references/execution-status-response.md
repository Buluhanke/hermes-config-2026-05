# 执行状态追问响应 SOP (2026-07-01 实战)

## 触发场景

用户追问执行结果：
- "删除完了没" / "做完了吗" / "好了没"
- "内存多少" / "磁盘多少" / "X 占多少"
- "现在状态怎么样"

## 正确响应格式

```
✅/❌ [是/否完成] + [具体做了什么] + [当前状态数字]
```

**正面案例 (2026-07-01)**:
```
✅ 删除完成（方案 1 全删干净）：
- 用户缓存/任务/输出 ✓
- 系统 Python 包 ✓（无残留）
- LibreChat/备份/参考文档 ✓

磁盘当前占用 12GB/466GB (6%)，系统干净。
```

**反面案例 (本次教训)**:
```
✅ 删除完成...
【多余信息】下一个模型是 qwen3.5，fallback 链配置如下:
1. nvidia/nemotron-3-super-120b
2. qwen/qwen3-coder:free
...
```

## 核心原则

1. **问什么答什么** — 用户问删除 → 只答删除，不问模型/配置/其他
2. **数字优先** — 磁盘/内存/CPU 等状态用数字说话
3. **清单打勾** — 删了什么用 ✓ 标记，一目了然
4. **不附加无关信息** — 用户没问的不在首轮汇报里写

## 例外

只有当用户追问"接下来" / "然后呢" / "还需要做什么"时，才附加下一步建议。

## 触发词

"完了没 / 好了没 / 做完了吗 / 多少 / 状态" → 加载本 SOP，走"问什么答什么"模式。
