## 关键教训

### Chrome DMG 陷阱
`curl` 下载 DMG 是 ChromeLite stub（47.0），不是完整 Chrome。必须用 Homebrew Cask。

### LanceDB embedder 环境隔离
独立进程（gateway 子进程/execute_code 沙盒）读不到 `.env` 中的 `OPENROUTER_API_KEY` → `warm()` 成功但 `embed()` 静默失败 → 0行数据。解决方案：换 FastEmbed 本地 embedding。

### FastEmbed 模型（venv 已装 fastembed 0.8.0）
- 默认模型：`BAAI/bge-small-en-v1.5`（384维，多语言）
- 首次加载约 103 秒模型下载，之后秒级
- 可选升级：`BAAI/bge-small-zh-v1.5`（512维，中文优化）

### 工具执行环境差异
memory/数据库类测试必须用 terminal；execute_code 沙盒与本机环境隔离，不可用同一标准判断。
