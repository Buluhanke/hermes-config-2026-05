# 2026-07-07 升级发现记录

## LanceDB embedding 配置失败根因

**问题**：LanceDB memories 表 0 行，config.yaml 里 `embedding.api_key_env: OPENAI_API_KEY`，但这个 env var 不存在（只有 `OPENROUTER_API_KEY`）。embedding 静默失败 → 全部写入 0 行。

**修复**（已落地）：
```yaml
# ~/.hermes/config.yaml
plugins:
  entries:
    lancedb:
      embedding:
        provider: openai
        base_url: https://openrouter.ai/api/v1
        api_key_env: OPENROUTER_API_KEY   # ← 原来是 OPENAI_API_KEY（不存在）
        model: text-embedding-3-small
```

**验证**：OpenRouter 上 text-embedding-3-small 可用，1536维。

## Chrome 升级正确路径

**坑**：Google 官方 `dl.google.com/chrome/mac/stable/GoogleChrome.dmg` 下载到的是 ChromeLite stub v47（17968字节），不是完整 Chrome。

**正确路径**：
```bash
# 走 Homebrew（macOS）
rm -rf "/Applications/Google Chrome.app"
brew install --cask google-chrome
# 或 force reinstall
brew reinstall --cask google-chrome

# 验证
/Applications/"Google Chrome.app"/Contents/MacOS/Google\ Chrome --version
# 输出：Google Chrome 150.0.7871.47
```

**教训**：不要试图找 Google 官方 DMG URL，Homebrew 永远有最新 stable 版缓存。
