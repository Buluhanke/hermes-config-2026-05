# 快捷指令（Shortcuts）自动化

## 1. 为什么用快捷指令

### 系统级深度集成
快捷指令运行在 iOS/macOS 系统层，可直接调用：
- Calendar、Contacts、Reminders、Notes 等系统 App
- 文件管理、照片、Safari、地图
- 系统级 APIs（蓝牙、Wi-Fi、剪贴板、位置）

### 跨设备同步
- iPhone/iPad/Mac 自动同步快捷指令
- 通过 iCloud 保持一致的工作流
- Apple Watch 可运行简化版快捷指令

### 触发条件丰富
| 触发类型 | 说明 |
|---------|------|
| 时间/日期 | 特定时间、重复日程、闹钟 |
| 位置 | 到达/离开某地 |
| App 使用 | 打开/关闭特定 App |
| NFC | 扫描标签触发 |
| 快捷指令 App 内 | 手动一键运行 |
| URL Scheme | 通过链接调用 |
| Siri | 语音唤醒 |
| 自动化标签页 | Safari、Power App 等 |

## 2. Hermes 集成场景

### 场景一：语音录入采购需求

```
用户对 Siri/快捷指令说：
"我要采购 100 个手机壳，白色，预算 50 元以内"

快捷指令自动：
1. 语音转文字
2. 提取：品名=手机壳、数量=100、颜色=白色、预算=50
3. 通过 URL Scheme 调 Hermes：
   hermes://add?item=手机壳&qty=100&color=白色&budget=50
4. Hermes 写入采购列表或飞书/Notion
```

### 场景二：1688 报价单整理

```
快捷指令自动：
1. 读取剪贴板中的 1688 商品信息
2. 解析：价格、起订量、供应商
3. 格式化后调 Hermes：
   hermes://import?data=Base64编码的JSON
4. Hermes 整理入库、去重、对比历史价格
```

## 3. URL Scheme 调用

### 快捷指令 → Hermes

在快捷指令中使用"打开 URL"动作：

```
hermes://add?item=ITEM_NAME&qty=QTY&memo=MEMO
hermes://search?keyword=KEYWORD
hermes://task?action=complete&id=TASK_ID
```

### Hermes → 快捷指令

Hermes 通过 HTTP 或打开 URL 触发：

```
shortcuts://run-shortcut?name=采购录入&input=text
```

### 双向通信示例

```
快捷指令侧：
┌─────────────────────────────────┐
│ 1. 语音录入                      │
│ 2. 解析结构化数据                │
│ 3. hermes://add?item=...        │  → Hermes 处理
│ 4. 等待结果反馈                  │
│ 5. 显示确认/重新录入             │
└─────────────────────────────────┘

Hermes 侧：
┌─────────────────────────────────┐
│ 1. 接收数据                      │
│ 2. 写入数据库/表格               │
│ 3. 触发后续流程                  │
│ 4. 返回处理结果 (App 通知/剪贴板) │
└─────────────────────────────────┘
```

## 4. 与 n8n 的对比

| 维度 | 快捷指令 | n8n |
|------|---------|-----|
| **适用场景** | 个人效率、日常自动化 | 业务流程、团队协作 |
| **部署方式** | 无需部署，本地运行 | 自托管或云端 |
| **触发条件** | 丰富（时间/位置/NFC/Siri） | 主要是 Webhook/定时 |
| **数据处理** | 轻量，适合单次处理 | 强大，支持复杂工作流 |
| **跨平台** | Apple 全家桶 | 任何平台（浏览器） |
| **与 Hermes 集成** | 适合语音/移动端触发 | 适合服务端自动化 |
| **学习曲线** | 低，上手快 | 中等，需了解工作流概念 |

### 选择指南

**用快捷指令：**
- 移动端语音录入
- 位置相关的自动化（如到家提醒）
- iPhone/Mac 上的快速操作
- 简单的数据采集和传输

**用 n8n：**
- 需要复杂条件分支的工作流
- 多系统对接（CRM、ERP、电商平台）
- 需要 Webhook 接收外部数据
- 团队共享的自动化流程

## 5. 入门建议

### 从简单开始

**第一步：手动触发**
- 创建"一键记录灵感"快捷指令
- 调 Hermes：`hermes://note?text=灵感内容`

**第二步：语音触发**
- 添加 Siri 短语
- 说"记一下"自动录入

**第三步：添加条件**
- 识别关键词自动分类
- 例如：包含"采购"→ `hermes://add?category=purchase`

### 逐步增加条件

```
Level 1: hermes://note?text=Hello
Level 2: hermes://note?text={clipboard}
Level 3: hermes://add?item={提取品名}&qty={提取数量}
Level 4: 语音 + AI 语义解析 + 多步骤确认
```

### 推荐学习路径

1. **Day 1-2**：创建 3 个简单快捷指令（笔记/提醒/剪贴板）
2. **Day 3-5**：学习 URL Scheme 调用 Hermes
3. **Week 2**：添加条件分支和变量处理
4. **Week 3**：结合位置、NFC 等触发器
5. **Month 2**：与 n8n 配合，处理复杂业务逻辑

### 常用快捷指令模板

| 模板名称 | 功能 |
|---------|------|
| 快速记账 | 语音/剪贴板录入金额和类目 |
| 采购清单 | 添加采购项并同步到表格 |
| 会议纪要 | 录音 → 转文字 → 调 Hermes 整理 |
