# Obsidian AI

## When to Use
使用Obsidian做本地知识管理时。需要语义搜索、笔记摘要、或AI辅助写作。本地优先，保护隐私。

## Core Features
- **Semantic Search**：基于语义的笔记搜索
- **笔记摘要**：长笔记一键生成摘要
- **AI写作助手**：润色、续写、翻译
- **问答系统**：针对笔记库的自然语言问答
- **本地运行**：数据完全本地存储

```bash
# 安装社区插件
# Settings → Community Plugins → 搜索"Local REST API"

# 配置AI插件（如Copilot插件）
# Settings → Copilot → 设置API Provider

# 常用命令
# Ctrl+P → 输入"AI"查看可用命令
```

## Pitfalls
- 需要额外配置本地/远程AI
- Semantic Search需向量化插件
- API配额和成本需关注
- 复杂笔记结构检索质量下降
