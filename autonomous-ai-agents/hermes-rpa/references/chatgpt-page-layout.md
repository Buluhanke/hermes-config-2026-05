| 元素 | 区域/坐标 | 说明 |
|------|----------|------|
| 窗口左上角 | (0, 30) | 含Chrome标题栏高度 |

| 左侧栏 | x=0~260 | 对话历史、导航 |

| 新聊天按钮 | (x=~50, y=~100) | 左侧栏顶部 |

```

# x=280 (略过侧栏边距)
# y=80  (去掉顶部工具栏)
# w=1600 (主内容区)
# h=700  (避开底部输入框)
```

## 坐标计算公式（通用，不硬编码）

```python
# 获取窗口
win = get_chrome_window()

# 侧栏宽度 (固定比例, 约窗口宽度的13.5%)
sidebar_w = int(win["width"] * 0.135)  # 1920→260

# 输入框 Y坐标: 窗口底部向上80px
input_y = win["y"] + win["height"] - 80

# 输入框 X坐标: 主内容区中心偏左
input_x = win["x"] + sidebar_w + (win["width"] - sidebar_w) // 2

# 内容截图区域 (避开侧栏、顶栏、输入框)
content_region = (
    win["x"] + sidebar_w + 20,    # 加右边距
    win["y"] + 60,                # 顶栏
    win["width"] - sidebar_w - 40, # 主内容宽度
    win["height"] - 160            # 底栏
)
```
