# 屏幕理解/真人化技术调研 2026-05-17

## 核心发现

### 1. GLM-PC（智谱）- 已发布1.1版
- **产品定位**：基于 CogAgent 的商业产品，全球首款面向公众的即用型电脑智能体
- **能力**：类似人类的视觉感知与操作电脑，能订票、预订酒店、朋友圈发文、淘宝购物等
- **技术路线**：截图 → VLM理解屏幕 → 虚拟鼠标键盘执行，与 OpenAI Operator 一致
- **平台**：Mac + Windows，**免费下载**
- **开源底座**：CogAgent（THUDM/CogVLM），CVPR 2024

### 2. Qwen2.5-VL 视觉Agent
- **模型本身已支持作为视觉Agent**：Qwen2.5-VL 直接具备使用电脑和使用手机的能力
- **开源**：https://github.com/THUDM/CogVLM
- **本地部署**：Ollama + qwen2.5vl:7b（已在 hermes-vision-connect 中配置）
- **移动端**：Qwen2.5-VL 能控制PC和移动设备GUI

### 3. ShowUI（开源）
- **GitHub**：showlab/ShowUI
- **定位**：开源、端到端、轻量级的视觉-语言-动作模型，专为 GUI Agent & Computer Use 设计

### 4. AutoGLM-Web（智谱）
- 已在智谱清言插件中对外开放
- 能模拟用户访问网页、点击网页、搜索、总结
- 基于 WEBRL 自进化在线课程强化学习框架

## 技术路线对比

| 方案 | 类型 | 费用 | 难度 | 成熟度 |
|------|------|------|------|--------|
| GLM-PC | 商业产品 | 免费 | 低（即装即用） | ⭐⭐⭐⭐ 已发布 |
| Qwen2.5-VL + Ollama | 本地开源 | 0 | 中（需集成） | ⭐⭐⭐ 已在用 |
| CogAgent 直接用 | 开源模型 | 0 | 高（需自己接） | ⭐⭐⭐ |
| ShowUI | 开源VLA模型 | 0 | 高 | ⭐⭐ 新出 |
| OpenAI Operator | 商业 | $200/月 | 低 | ⭐⭐⭐⭐ |

## 真人化缺口分析（2026-05-17）

| 模块 | 当前状态 | 缺口 |
|------|---------|------|
| 视觉感知 | 有基础（CUA + 截屏） | 缺专门VLM做语义理解，Qwen2.5-VL已可补充 |
| 移动端Agent | 100%空白 | 智谱/豆包已能做手机Agent |
| 鼠标轨迹 | 有（过冲+发呆机制） | 基础够用 |
| 验证码处理 | 100%空白 | 仍是卡点 |
| 情感语音 | 有TTS，缺ASR | TTS已有MOSS/Edge，ASR未集成 |

## 建议优先路径

1. **立即可做**：Qwen2.5-VL 本地Ollama（已在hermes-vision-connect中）
2. **值得尝试**：GLM-PC 免费下载作为对比参照
3. **长期关注**：ShowUI 开源进展
