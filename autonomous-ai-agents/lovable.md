# Lovable

## When to Use
想快速从自然语言描述生成可交互UI时；GPT Engineer的轻量替代品；需要快速验证UI想法、制作原型。

## Core Features
- **对话驱动UI**：输入文字描述，AI生成完整前端页面
- **多轮迭代**：可针对生成结果继续对话修改
- **即时预览**：生成即渲染，支持移动端预览
- **导出代码**：下载React/Next.js代码到本地
- **模板市场**：提供预制模板快速启动

## Quick Start
1. 访问lovable.dev，注册登录
2. 点击"New Project"描述项目需求
3. AI生成初始UI，可继续对话修改
4. 满意后点击"Export"下载代码

## Pitfalls
- 免费版生成次数有限
- 复杂业务逻辑（后台系统、数据处理）支持弱
- 导出代码依赖其自有的组件库
- 对中文UI描述理解度弱于英文
