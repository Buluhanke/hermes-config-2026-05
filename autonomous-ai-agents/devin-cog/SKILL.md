# Devin — AI软件工程师认知架构

## When to Use
- 复杂多步骤编程任务需要长期规划
- 需要深度理解代码库结构后进行修改
- 需要自我纠错和迭代优化的任务

## Core Features
- **MCP集成**：Model Context Protocol连接外部工具
- **代码库理解**：通过搜索/阅读建立项目全局认知
- **任务分解**：大问题拆解为可验证的小任务
- **沙盒执行**：代码修改后在隔离环境验证
- **迭代优化**：根据执行结果自我纠错

## Quick Start
```bash
# Devin典型工作流
1. 任务描述 → Devin解析需求
2. 代码库探索 → 建立上下文
3. 任务规划 → 分解为步骤
4. 分步执行 → 每步验证
5. 迭代优化 → 失败则回退重试

# MCP工具示例
- 文件读写、代码搜索
- 命令行执行、Git操作
- Web搜索获取文档
```

## Pitfalls
- 任务拆解过粗导致执行失败
- 沙盒环境与生产环境差异
- 长任务中上下文丢失
- 过度探索代码库浪费时间
- 自我纠错循环导致死循环
