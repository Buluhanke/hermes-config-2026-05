## 1. 搜货（尺寸词 + 彩盒定制 双词，江浙沪）
- **矩阵式卖家只在「彩盒定制」池**，只搜 `8*8*9cm纸盒` 抓不到他们（坑31）。必须两组合并：
  - 词① `8*8*9cm纸盒`（GBK `%D6%BD%BA%D0`）
  - 词② `彩盒定制`（GBK `%B2%CA%BA%D0%B6%A8%D6%C6`）
- 端点：`https://s.1688.com/selloffer/offer_search.htm?keywords=<GBK>&province=%E6%B1%9F%E8%8B%8F,%E6%B5%99%E6%B1%9F,%E4%B8%8A%E6%B5%B7`（province=江浙沪）
- 翻页：URL 加 `&beginPage=2` 等。
- 提取 offerId：用 AppleScript 注入 `scripts/extract_ids.js` 读 `document.documentElement.outerHTML`，正则 `detail.1688.com/offer/(\d+)`。
- **提纯**：搜结果 JSON 不能直接当 ID 喂详情页（坑32）。用 python 取 `ids` 字段过滤纯数字 9-14 位，写每行一个文件（如 `/tmp/ids.txt`）。

## 2. 尺寸验证（矩阵式 + 连写双识别）
- 用 `scripts/verify_carton_matrix.js`（已修全角左括号 `（` 漏判，坑30）。
- 驱动：AppleScript 读文件列表逐 URL 注入，输出 `offerId \t JSON`。
- JSON 字段：`isCarton`(尺寸命中) / `matrixHit`(矩阵式长宽×高) / `connectedHit`(连写L*W*H) / `title`。
- **注意**：命中 ID ≠ 该尺寸有货！矩阵卖家 SKU 轴范围不同（盒骏高3-22cm常规，瀚拓高350cm+立柱）。必须进第 3 步验证具体尺寸组合真存在。

## 3. 价格 / 库存提取（环节⑦升级版，最稳）
- 用 `scripts/price_mtop_capture.py`（Playwright 接管 9333 实例，抠内联 `skuMapOriginal`）。
- 用法：
  ```bash
  python3 scripts/price_mtop_capture.py <offer_id> [8*8*9]
  # 不传尺寸 -> 回显全部 SKU；传 8*8*9 -> 只回显该尺寸组合
  ```
- 返回：每个 SKU 的 `spec`(如 `8x8（长宽）;9cm（高）`) + `price`(discountPrice真实成交价) + `stock`(canBookCount实时库存)。
- 实测：677701816838 的 8×8×9=¥0.19/库存78万、9×9×10=¥0.23/库存54万。
- **比旧 `price_clean3.js`（DOM 点击）稳**：不依赖渲染、不踩 size-bar、拿全 SKU 表。

## 4. 复活 9333 实例（关了或登录态失效时）
```bash
# 起独立实例（独立 profile，不碰默认 Chrome）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9333 \
  --user-data-dir="$HOME/.chrome_1688_scraper" \
  --no-first-run --no-default-browser-check \
  --window-name="1688-Scraper-9333" about:blank &
```
- 登录态 Cookie 落在 `~/.chrome_1688_scraper`，一般重起不用重登。
- 若提示未登录（页面无价格/跳登录墙）→ 用 Playwright 打开 `https://login.1688.com/login.htm` 让你扫码一次。
- **禁用**：不要连 127.0.0.1:9222（那是默认 Chrome 的僵尸端口，非标准 CDP，MCP 也连不上）。

## 5. 常见坑（踩过的，别再踩）
- 坑30：矩阵式尺寸 `9cm（高）` 是全角左括号 `（`（左括号），正则必须 `[（）()]*` 都放。
- 坑31：矩阵卖家（彩盒定制类）只在「彩盒定制」搜索池，尺寸词搜不到 → 双词合并。
- 坑32：搜结果 JSON 不能直接当 ID 喂详情页 → 先提纯成纯数字 ID 列表。
- `queryofferskuselectormodel` MTOP 包在 2026 已弃用，SKU 改内联 HTML（`skuMapOriginal`），别再监听 MTOP。
- `networkidle` 在 1688 永远不空闲 → 用 `domcontentloaded` + 固定等待。
