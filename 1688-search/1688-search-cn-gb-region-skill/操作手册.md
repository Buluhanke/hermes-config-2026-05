## 1. 搜货（尺寸词 + 彩盒定制 双词，江浙沪）
- **矩阵式卖家只在「彩盒定制」池**，只搜 `25*13*32cm牛皮纸袋` 抓不到他们（坑31）。必须两组合并：
  - 词① `25*13*32cm牛皮纸袋`（GBK：25*13*32cm=%32%35%2A%31%33%2A%33%32%63%6D，牛皮纸袋=%C5%A3%C6%A4%D6%BD%B4%FC）
  - 词② `彩盒定制`（GBK `%B2%CA%BA%D0%B6%A8%D6%C6`）
- 端点：`https://s.1688.com/selloffer/offer_search.htm?keywords=<GBK>&province=%E6%B1%9F%E8%8B%8F,%E6%B5%99%E6%B1%9F,%E4%B8%8A%E6%B5%B7`（province=江浙沪）
- 翻页：URL 加 `&beginPage=2` 等。
- 提取 offerId：AppleScript 注入 `scripts/extract_ids.js` 读 `document.documentElement.outerHTML`，正则 `detail.1688.com/offer/(\d+)`。
- **提纯**：搜结果 JSON 不能直接当 ID 喂详情页（坑32）。用 python 取 `ids` 字段过滤纯数字 9-14 位，写每行一个文件（如 `/tmp/ids.txt`）。

## 2. 尺寸验证（矩阵式 + 连写双识别）
- 用 `scripts/verify_carton_matrix.js`（已修全角左括号 `（` 漏判，坑30）。
- 驱动：AppleScript 读文件列表逐 URL 注入（仿 `check_batch.scpt`，`delay 8` 防验证码），输出 `offerId \t JSON`。
- JSON 字段：`isCarton`(尺寸命中) / `matrixHit`(矩阵式长宽×高) / `connectedHit`(连写L*W*H) / `title`。
- **命中 ID ≠ 该尺寸有货**！矩阵卖家 SKU 轴范围不同（盒骏高3-22cm常规，瀚拓高350cm+立柱）。须用价格脚本验证具体尺寸组合真存在。

## 3. 价格 / 库存提取
- **首选**：AppleScript 驱动默认 Chrome + `scripts/price_clean3.js`（DOM 抠价，已验证稳，不触发风控）。
- **备选（脆弱，坑33）**：`scripts/price_mtop_capture.py` 用 Playwright 接管 9333 实例抠内联 `skuMapOriginal`。仅当 AppleScript 不可用且你明确要时用，且批量必降速（每页 6-8s + Captcha 检测）。

## 7. ⚠️ 搜页风控（验证码拦截）规避方案（2026-08-24 实测）
**症状**：短时间多次搜页（s.1688.com/selloffer）后，搜页返回「验证码拦截」，但**详情页（detail.1688.com/offer）始终畅通**。
**根因**：搜页端点对自动化频率极敏感，连搜多轮把会话打标；详情页宽松。
**解决（已写进 cdp1688.py）**：
1. **搜索循环自动退避**：`search_page_captcha()` 检测验证码 → 指数退避（15/30/45/60s，上限4）等恢复，不在被拦时硬撞；重试仍拦则跳过该词。
2. **搜验解耦**：搜一次拿 ID 池，之后所有核验走**详情页通道**（detail.1688.com 畅通），不反复搜。
3. **移动端搜页绕行**：`python3 cdp1688.py ... --mobile` → 改用 `m.1688.com/offer_search.html`（风控模型不同，实测 121 候选无码）。
4. **人工过码**：被拦且退避无效时，截图给用户点一下验证码，session 恢复后好一阵。
**关键约束**：同一浏览器实例**绝不同步跑两个搜索进程**（会互相触发风控，坑：proc 并行共享 9222 导致 0 候选）。一次只跑一个搜索/核验任务。
**组合串尺寸写法**：`extract_sizes_from_spec` 现支持全角【】轴名组合（宽【26cm】高【10cm】;特硬;长【46cm】=26*10*46），核验主循环从只查 skuMapOriginal.specAttrs 扩为「整页 outerHTML 逐段抽尺寸」兜底，顺序无关匹配用 `target_perms()`。
**典型坑**：V2 跑 200 候选 + 多次重搜 → 搜页被打死；结果 JSON 在写盘前被风控掐断（脚本需确保最终写盘，见 cdp1688.py 收尾 `json.dump`）。
