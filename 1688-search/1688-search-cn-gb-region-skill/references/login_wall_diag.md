# 1688 登录墙诊断（"搜出全是其他品"/0命中 根因）

> 2026-08-25 实战复盘。会话里"找的袋子全是茶叶/铝箔/食品袋"的表象，根因不是搜词错，是 **后台 CDP 实例的 1688 登录态丢了**。

## 因果链

1. 后台 CDP Chrome（`chrome-cdp-profile` + cookie 注入）的 1688 登录态**会静默丢失**。
2. 搜页 `s.1688.com/selloffer/...` 登录态一掉 → 请求被踢去 `login.taobao.com` 中转 → **返回 0 候选**。
3. 脚本只能靠详情页直开（detail 端点偶尔还能读）拿到少量 ID；验证脚本品类门槛若太松，就把**茶叶自封袋/铝箔自封袋/牛皮纸自封袋**这些广义"自封袋"（标题含"自封袋"且满足尺寸）全收了。
4. 用户看到"全是其他品" = 茶叶袋/铝箔袋，不是要的"白边*12丝塑料自封袋"。

## 识别信号（开跑前/开跑中）

| 信号 | 含义 |
|---|---|
| 搜页 `location.href` 含 `login.taobao` 或页面含"验证码" | 搜页登录墙，0 候选 |
| 详情页 `document.title` 含"淘宝网" 或 无 `skuMapOriginal` | 详情页登录墙 |
| 短词（白边自封袋/塑料自封袋）返回 0 候选，但长精确词反而有候选 | 反过来想：长词稀释后排进无关品；短词 0 候选=登录墙 |
| 重注后搜"白边自封袋"立刻出 ~10 候选，登录掉时同样词 0 | 确诊登录态波动 |

## 修复（已落地 cdp1688_bag.py）

- **品类硬卡**：`BAG_PLASTIC`(塑料/PE/opp) + `BAG_EXCLUDE`(茶叶/铝箔/食品/牛皮纸)。非塑料自封袋一律跳过，茶叶/铝箔袋不再误收。
- **搜索阶段登录墙检测 + 自动重注**：导航前探 `login.taobao`/验证码，连续2次自动调 `reauth_cookies` 重注。
- **详情页登录墙**：连续2次重注，阈值提到8才停（坑39）。

## 根本约束（无法靠脚本彻底解决）

`chrome-cdp-profile` 是独立 Profile，跟**用户默认 Chrome 不共享登录态**。1688 对它风控极严——重注后也撑不过几十个详情页就再掉。这是文档坑39 早定论的：**真·稳定解法 = 用户在默认 Chrome 保持 1688 已登录**（助手不能代扫）。

## FAIL-FAST 做法（推荐）

任何全量任务前先跑 `scripts/preflight_1688.py`：
- 探 9222 在线 → 探已知 detail 页登录态 → 探一个搜索词候选数。
- 任一项 FAIL 立刻停，先 `bash start_cdp_1688.sh` 重注，仍 FAIL 就让用户回默认 Chrome 登录 1688。
- 避免 15 分钟白跑、最后发现全是无关品。

## 绕开搜页的兜底

登录态不稳时，改用主驱动 `--reverify IDFILE` 模式：只验用户/历史已给的已知 offerId 池（每行一个），不依赖搜页。ID 来源：历史 results、同款推荐、用户发来的链接。
