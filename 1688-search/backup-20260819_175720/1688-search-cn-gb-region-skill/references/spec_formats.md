# 1688 规格写法实测样本（来自真实详情页 innerText）

## 连写（最常见，正则 JOINED 覆盖）
- `17.5*17.5*8.5cm;特硬B/A`   （星号，小写cm）
- `17.5x17.5x8.5cm;特硬B/A`   （小写x，小写cm）
- `17.5*17.5*8.5CM`           （星号，大写CM）
- `16*16*16cm`                 （16方箱）
- `35*35*17.5CM`              （混尺寸同店）

## 拆写（飞机盒，需 SQ 双匹配）
- 长*宽行：`17.5*8.5(长*宽),18.5*8.5(长*宽)...`
- 高行：`8.5cm（高 ）`
- 即底面 17.5×8.5 + 高 8.5 → 不是正方形底面，用户要 17.5×17.5×8.5 时不命中
- 正方形飞机盒写法：`17.5*17.5(长*宽)` 配 `8.5cm（高）` → SQ 命中
