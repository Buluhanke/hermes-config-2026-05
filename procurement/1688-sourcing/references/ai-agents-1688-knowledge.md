## Gemini (https://gemini.google.com) ✅

**2026-05-29 测试**

回复要点：
1. **方案一（推荐）：商业数据 API 接口**
   - 奇沙数据（qsy.cn）、魔法API 等
   - 数据全、接口稳定
   - 适合长期做采购自动化的

2. **方案二：第三方数据平台**
   - 俺搜网、爱收藏 等
   - 1688 商品数据 + 分析工具
   - 有免费额度

3. **方案三：RPA 半自动**
   - 模拟人类行为，依然会遇到验证码
   - 可暂停让人类手动解决（半自动）

**结论**：不推荐硬刚验证码，最靠谱的是商业 API 或第三方平台。

## 智谱清言 (https://chatglm.cn) ✅

**2026-05-29 测试**

回复要点（部分截取）：

- RPA 半自动方案（仍会遇到验证码，需人工介入）

**结论**：与 Gemini 一致，不建议硬撞验证码。
