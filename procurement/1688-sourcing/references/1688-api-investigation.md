# 1688开放平台API调研结论（2026-05-29）

## 结论：不适合中小买家

### ISV入驻申请条件（已验证）
- 企业支付宝（已认证）
- 营业执照（必须）
- 审核时间2-3工作日
- 必须有实际店铺/商业主体

### 适合场景 vs 不适合场景

| 适合 | 不适合 |
|------|--------|
| 1688卖家（有店铺） | 纯买家（从1688进货的贸易商） |
| 有开发能力的技术公司 | 中小贸易商/个人采购 |
| 需要批量发布商品/管理订单 | 只需要搜索、比价、找供应商 |

### 迅龙贸易的情况
- 身份：买家（从1688采购，不是卖货）
- 需求：搜索1688商品 → 找供应商 → 比价
- 结论：无法申请到适合的API，只能用CDP拦截或anysearch

### 可用的替代方案

1. **AnySearch**（已验证✅）
   - 速度最快，不触发反爬
   - 适合批量搜索和摘要数据
   - 局限：无法抓取商品详情页的规格/颜色/尺寸

2. **CDP拦截postMessage**（条件受限⚠️）
   - 需要用户已登录Chrome
   - headless Chrome会被1688检测并弹出滑块验证码

3. **extract提取详情页**（可用✅）
   - 反爬比搜索页轻，商品详情页可以访问
   - 可以提取公司信息、联系方式等

### 2026-05-29实测记录
- 直接访问s.1688.com → 100%触发滑块验证码
- headless Chrome → 立即被检测
- 用户本地Chrome → 9222端口被占用/random port，无法连接
- anysearch → 可用，数据有限但快速
- 详情页extract → 可用，数据较全
