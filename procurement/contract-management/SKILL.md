# 采购合同与订单管理

## 1. 采购合同核心条款

采购合同是买卖双方权利义务的法律依据，以下为核心条款清单：

### 1.1 标的条款
- **品名**：产品标准名称（与SKU对应）
- **规格**：型号、材质、尺寸、性能参数
- **数量**：件数、重量、体积单位
- **单位**：包装规格、最小起订量

### 1.2 价格条款
- **单价**：含税价/不含税价标注
- **总价**：大写金额
- **币种**：人民币/美元/欧元
- **价格条件**：FOB/CIF/DDP/EXW

### 1.3 交期条款
- **交货日期**：具体日期或阶段
- **交货地点**：目的地/仓库/指定物流
- **物流方式**：快递/物流/专车/自提
- **延期责任**：延迟一天扣款比例

### 1.4 付款条款
- **付款方式**：支付宝/对公转账/信用账期
- **付款节点**：预付/到付/月结30天
- **账期起始**：发票日期/签收日期
- **逾期利率**：滞纳金计算标准

### 1.5 验收条款
- **验收标准**：国标/行标/企标/样品确认
- **验收方式**：全检/抽检/免检
- **异议期**：收货后多少天内可提出
- **不良品处理**：退货/补发/折价

### 1.6 违约条款
- **违约金上限**：合同总额的百分比
- **不可抗力**：自然灾害/政策变更处理
- **单方解除权**：提前通知天数
- **争议解决**：仲裁/诉讼管辖法院

## 2. 1688电子合同流程

### 2.1 合同签署流程

```
订单确认 → 合同条款协商 → 电子签章 → 双方确认 → 合同生效
```

1. **发起合同**：在1688订单详情页点击"创建合同"
2. **填写条款**：录入品名/数量/价格/交期等核心信息
3. **选择签章**：企业账号需上传公章或个人账号绑定的电子签名
4. **对方确认**：供应商签署后需方进行确认
5. **合同存档**：签署完成后自动归档至"我的合同"

### 2.2 合同存档与检索

**存档路径**：1688 → 买家工作台 → 交易管理 → 我的合同

**检索方法**：
- 按订单编号搜索
- 按供应商名称筛选
- 按时间区间筛选
- 按合同状态（待签署/已签署/已作废）

**下载备份**：支持PDF格式下载，建议重要合同本地备份

## 3. 合同履约跟踪

### 3.1 三维度跟踪体系

| 维度 | 跟踪指标 | 预警阈值 | 处理措施 |
|------|----------|----------|----------|
| 按时 | 交期达成率 | 延迟≥3天 | 发货催促函 |
| 质量 | 来料合格率 | 合格率<98% | 质检报告+索赔 |
| 数量 | 订单齐套率 | 短装≥5% | 补货+扣款 |

### 3.2 按时跟踪

**执行动作**：
- 订单交期前3天发确认函
- 交期当天跟进发货状态
- 延迟后每天跟踪物流进度
- 超7天未发货启动投诉

### 3.3 质量跟踪

**执行动作**：
- 到货后2天内完成质检
- 不良品拍照留证
- 填写来料不良报告（IQC）
- 48小时内提交供应商改善报告

### 3.4 数量跟踪

**执行动作**：
- 对照订单核对来货数量
- 记录实际收货数量与订单差异
- 短装部分发补货通知
- 超耗部分做退换或扣款处理

## 4. 纠纷处理

### 4.1 证据保存规范

**截图类**：
- 聊天记录（含时间戳）
- 订单快照（含价格/数量/交期）
- 物流轨迹截图
- 来货照片（箱体/产品/铭牌）

**文件类**：
- 合同PDF（含电子签章）
- 发票原件
- 质检报告
- 快递签收单

**保存期限**：至少2年（合同有效期+诉讼时效）

### 4.2 1688平台仲裁

**申请路径**：订单详情 → 申请售后 → 选择原因 → 提交证据

**适用场景**：
- 货不对板
- 质量问题
- 延迟发货
- 退款纠纷

**仲裁材料准备**：
1. 订单编号及合同截图
2. 沟通记录截图
3. 实物证据照片
4. 损失计算明细

### 4.3 法律途径

**轻微纠纷**：发送律师函（通过平台或直接送达）

**合同仲裁**：
- 约定仲裁条款
- 提交仲裁委员会
- 仲裁裁决强制执行

**诉讼管辖**：
- 合同约定管辖法院
- 被告所在地法院
- 合同履行地法院

## 5. 合同存档命名规范与检索方法

### 5.1 命名规范

**命名格式**：
```
[供应商简称]_[品名简写]_[订单号]_[签署日期].pdf
```

**示例**：
```
深圳华腾_五金配件_PO20250315_20250320.pdf
杭州中盛_包装材料_1688订单_20250401.pdf
```

**禁止字符**：/ \ : * ? " < > |

### 5.2 目录结构

```
采购合同/
├── 2025年/
│   ├── Q1/
│   │   ├── 3月/
│   │   └── 4月/
│   └── Q2/
│       ├── 5月/
│       └── 6月/
└── 2024年/
    └── 归档/
```

### 5.3 检索方法

**本地检索**：
- 使用Everything/Listary按供应商名称检索
- 按订单号精确检索
- 按日期范围筛选

**元数据记录表**（Excel）：
| 合同编号 | 供应商 | 品名 | 金额 | 签署日期 | 到期日期 | 存放路径 |
|----------|--------|------|------|----------|----------|----------|
| PO20250315 | 深圳华腾 | 五金配件 | 12500 | 2025-03-20 | 2025-06-20 | ... |

**定期整理**：每月末整理当月合同，每季度末清理已履约合同并归档
