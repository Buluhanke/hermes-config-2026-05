# 供应商关系管理

## 概述

供应商不只是交易对象，是业务伙伴。好的供应商关系能带来：优先供货、账期支持、品质保障、新品共享。

## 供应商分层

### 四层模型
| 层级 | 定义 | 合作策略 | 维护频率 |
|------|------|---------|---------|
| 战略层 | 年度采购>10万，核心资源 | 高层对接，联合规划，账期支持 | 月度联系 |
| 优选层 | 年度采购>3万，稳定需求 | 优先订单，关系维护，快速响应 | 季度联系 |
| 普通层 | 年度采购<3万，按需采购 | 市场化合作，价低者得 | 按需联系 |
| 淘汰层 | 问题供应商 | 尽快终止合作，资料归档 | 不维护 |

### 分层依据
```python
供应商分层 = {
    "战略层": 年度采购额 > 100000 and 合作年限 > 2 and 评分 > 4.6,
    "优选层": 年度采购额 > 30000 or 合作年限 > 1 and 评分 > 4.4,
    "普通层": 其他正常供应商,
    "淘汰层": 纠纷率 > 5% or 连续2次质量问题 or 欺诈行为,
}
```

## 长期合作策略

### 年度框架协议
```
【标题】年度采购框架协议

【甲方】义乌市迅龙贸易有限公司
【乙方】XXX公司

【协议内容】
1. 合作期限：2024年1月1日至2024年12月31日
2. 产品范围：纸箱、飞机盒及相关包装材料
3. 定价机制：随行就市，批量优惠见附件
4. 账期支持：月结30天
5. 最低采购量：每月不低于XXXX元
6. 优先供货：甲方订单优先排产
7. 新品共享：乙方新品优先推荐甲方
```

### 账期谈判
- 新供应商：现款现货或30%预付
- 合作6个月后：根据采购额谈月结30天
- 战略层供应商：可谈月结60天+银行承兑

### 联合开发
- 新产品研发阶段邀请供应商参与
- 供应商提供材质/工艺建议
- 共享专利和收益（特殊情况）

## 关系破裂处理

### 和平分手（优先选择）
```python
和平分手条件 = {
    "供应商主动终止": True,
    "没有未解决纠纷": True,
    "未来可能重新合作": True,
}

和平分手流程 = """
1. 书面说明原因（不是因为严重问题）
2. 结清所有账款
3. 感谢多年合作
4. 保留联系方式（未来可能）
5. 资料归档，不删除档案
"""
```

### 强制淘汰（不得已）
```python
强制淘汰条件 = {
    "严重质量问题": True,
    "欺诈行为": True,
    "多次沟通无效": True,
}

强制淘汰流程 = """
1. 停止新订单
2. 完成已有订单（监督下）
3. 结清账款
4. 通知相关人员（内部）
5. 拉黑（1688/微信）
6. 档案标注"永久淘汰"
"""
```

### 纠纷未解决时的处理
1. 平台仲裁优先
2. 保留所有证据
3. 不升级线下冲突
4. 必要时法律途径
