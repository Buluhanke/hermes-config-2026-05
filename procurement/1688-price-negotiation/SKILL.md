# 1688 议价策略与技巧

## 概述

本 skill 提供在阿里巴巴 1688 平台上进行供应商议价的完整策略、话术和技巧，帮助采购人员以最优价格达成合作。

---

## 核心原则

1. **永远不要先暴露心理底价** — 先让供应商报价，摸清对方心理价位
2. **批量梯度报价** — 数量越大，单价越低，这是核心谈价逻辑
3. **对比三家才有筹码** — 拿到多个报价后才能有效压价
4. **情绪稳定，不卑不亢** — 有理有据，不急不躁，保持长期合作姿态

---

## 议价话术模板

### 首次询价
> "老板好，我们是义乌的电商，长期有纸箱需求，想问一下这个价格能优惠多少？"

**要点：** 表明长期合作意向，以问价开场，不直接报价

### 试探底价
> "别家给我们报了 X 元，你们能再低一点吗？"

**要点：** 给出竞争价格参考，试探对方降价空间

### 批量优惠
> "如果我们一个月能稳定走 5000 个，能再降多少？"

**要点：** 以稳定大批量订单为筹码，换取更深折扣

### 拖延策略
> "价格差不多了，但我还得再对比两家，明天给你回复"

**要点：** 给供应商留出主动降价的空间，制造竞争压力

### 最终确认
> "这个价格我这边可以接受，但能不能再送点运费或者给个账期？"

**要点：** 最后再榨取一点附加优惠

## 价格拆解策略

当供应商报价过高时，通过拆解成本结构寻找压价空间。

```
原报价：¥6.0/个
├── 纸板（原材料）：¥3.0
├── 印刷：¥0.8
├── 人工：¥0.5
├── 物流：¥0.4
└── 利润：¥1.3

成本结构分析：原材料 + 加工约 ¥4.3，占比 72%
结论：存在 ¥1-1.5 的压缩空间
```

### 拆解话术
> "老板，你们原材料成本大概多少？我这边有渠道可以核实"

**要点：** 暗示你对成本结构有了解，给供应商心理压力

## 批量梯度报价参考

| 数量范围 | 建议折扣 | 说明 |
|----------|----------|------|
| 100-500 | 基准价 | 首批小试单，不强行压价 |
| 500-1000 | 95 折 | 建立初步合作关系 |
| 1000-3000 | 90 折 | 稳定供货意向 |
| 3000-5000 | 85 折 | 大客户待遇 |
| 5000+ | 80 折以下 | 核心供应商价格 |

**提示：** 具体折扣需结合产品毛利和市场竞争情况灵活调整。

## 1688 特有问题处理

### 起订量（MOQ）过高
- **策略：** 争取小批量试单（50-100 个起），验证质量后再逐步增量
- **话术：** "我们先拿 100 个试试市场反应，好的话下周就可以下 1000 个的单"

### 运费另算
- **策略：** 争取含税含运费价格，将运费成本纳入总价对比
- **话术：** "老板，这价格含不含运费？我们要统一算成本"

### 账期问题
- **策略：** 月结 30 天需单独谈，通常需要牺牲部分价格
- **话术：** "我们希望能月结 30 天，价格能不能再让一点？"

### 定制产品
- **策略：** 确认最低起订量（MOQ）和打样费，打样费是否可抵扣大货
- **话术：** "打样费多少？后续大货能不能抵扣？"

## 议价流程总结

```
1. 货比三家 → 收集 3 家以上报价作为参考
2. 目标定价 → 根据市场均价设定心理价位（不暴露）
3. 首轮试探 → 让对方先报价，找差距
4. 批量施压 → 以量换价，给出目标数量
5. 拆分压价 → 拆解成本结构，寻找漏洞
6. 最后榨取 → 含运费、账期、样品等附加条件
7. 拖延确认 → 对比后再回复，留出对方主动让价余地
```

---

## 注意事项

- **不要群发话术** — 1688 供应商会识别群发信息，尽量个性化沟通
- **保持在线** — 询价后保持在线，即时响应更容易拿到好价格
- **复购承诺** — 明确表示复购意愿，增加供应商降价动力
- **旺季提前** — 旺季前提前备货，避免因供不应求导致价格坚挺
- **查看历史成交** — 通过供应商历史成交记录判断真实底价
