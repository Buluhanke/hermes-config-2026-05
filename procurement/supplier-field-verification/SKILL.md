# 供应商远程实地验证 | Supplier Field Verification

> 通过公开信息与数字工具，在实地考察前完成供应商可信度初筛，大幅降低踩坑概率。

---

## 1. 为什么远程验证重要

实地考察成本高（差旅 + 时间），但以下场景**不验证就考察 = 盲赌**：

| 风险类型 | 典型案例 | 远程验证可发现率 |
|----------|----------|------------------|
| 皮包公司 / 空壳 | 实际无工厂，租借别人车间 | ✅ 高 |
| 经营异常 | 被列入企业经营异常名录 | ✅ 极高 |
| 规模严重夸大幅度 | 声称500人实际不足50人 | ✅ 中高 |
| 合同纠纷记录 | 大量买卖合同诉讼 | ✅ 高 |
| 场地不存在 | 注册地址是住宅或虚拟地址 | ✅ 极高 |

**结论**：远程验证应作为**必经前置流程**，而非可选项。投入2小时，避免损失几十万。

## 2. 验证清单（四维度）

### 维度一：基础信息

- [ ] 公司全称、注册资本、成立时间
- [ ] 统一社会信用代码（与营业执照一致）
- [ ] 注册地址与实际经营地址是否一致
- [ ] 法定代表人身份（是否频繁变更）
- [ ] 经营范围是否覆盖目标产品类别

### 维度二：经营状态

- [ ] 是否被列入「企业经营异常名录」
- [ ] 是否存在「严重违法失信企业」
- [ ] 工商年报连续年份的社保人数（推算真实规模）
- [ ] 股东结构与关联公司（识别关联方交易风险）
- [ ] 是否有行政许可/备案（生产许可证、进出口权等）

### 维度三：能力验证

- [ ] 注册资金实缴情况（是否与宣传规模匹配）
- [ ] 商标/专利数量（研发能力侧面印证）
- [ ] 1688店铺年限与交易勋章等级
- [ ] 百度搜索供应商名称，看媒体负面报道
- [ ] 天眼查/企查查查看法律诉讼记录（建设工程/买卖合同纠纷）

### 维度四：风险信号

- [ ] 近3年有合同纠纷诉讼且我方为被告
- [ ] 员工评论（看准网/智联）集中反映拖欠工资
- [ ] 实际控制人有多家关联公司且陆续注销
- [ ] 注册地址在工业园区但无对应生产痕迹（Google Earth验证）
- [ ] 注册资本突增后短期内大额分红（套现嫌疑）

## 3. 验证工具

### 企查查 / 天眼查（必须）
- 免费信息：工商登记、股东结构、年报摘要
- 付费解锁：详细年报、隐藏关联方、诉讼详情
- 重点看：「经营异常」「严重违法」「司法风险」标签
- 网址：https://www.qcc.com / https://www.tianyancha.com

### 1688视频验证
- 要求供应商提供**工厂实时视频**（非宣传片）
- 视频应包含：生产线全貌、原材料仓库、办公区域
- 通过视频估算：机器设备型号数量、员工人数、场地面积
- 注意：宣传片≠实时视频，有条件建议视频通话抽查

### 百度街景 / 高德街景
- 输入供应商注册地址，查看实地卫星图/街景
- 关注：厂房外观、车辆停放情况（货车数量推断业务量）
- 若街景时间较早，结合Google Earth历史影像对比变化

### Google Earth Pro（免费）
- 功能：查看任意地址历史卫星影像（最长20年）
- 用途：识别场地是否长期稳定使用，还是临时租借
- 操作：输入地址 → 切换时间轴滑块查看建设进展

### 辅助工具

| 工具 | 用途 |
|------|------|
| 国家企业信用信息公示系统 | 免费工商数据，比企查查更权威 |
| 中国裁判文书网 | 查供应商诉讼记录（按公司名称搜索） |
| 启信宝 | 与企查查类似，可对比交叉验证 |
| 看准网 / 智联招聘 | 查看员工评论，侧面了解经营稳定性 |
| 百度地图 | 查看周边配套设施（工业区vs住宅区） |

## 4. 与1688认证的关系

1688提供多种认证体系，远程验证**不能替代**但可**补充**：

### 1688深度验厂
- 阿里委托第三方实地审核，报告可在商品详情页下载
- 验证内容：生产能力、质量管理、员工福利、现场管理
- **价值**：可信度高，有审核照片和视频
- **局限**：审核标准统一，无法覆盖所有行业特殊要求
- **建议**：有深度验厂报告的供应商，可降低实地考察频次

### 1688实力商家
- 门槛：注册资本+年交易额+买家保障
- **价值**：平台背书，降低基础欺诈风险
- **局限**：认证标准偏商业规模，非生产质量
- **注意**：实力商家≠产品德艺双馨，仍需独立验证

### 验证优先级建议

```
有1688深度验厂报告 + 远程验证无异常 → 可考虑免实地（小额首单）
有1688实力商家 + 远程验证无异常     → 实地考察优先级降低
无认证 + 远程验证有风险信号         → 必须实地考察
无认证 + 远程验证完全正常           → 建议实地考察（小额定金试单）
```
