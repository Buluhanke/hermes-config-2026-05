# 1688采购质量控制

## 概述

建立从"下单"到"复盘"的全链路质量控制体系，确保供应商提供的货物符合预期，减少损失。

## 来料检验流程

### 检验时机
- **即时检验**：收货时当场开箱，检查外包装
- **24小时内**：数量清点、规格核对
- **3天内**：功能性测试（小批量试单）

### 检验维度
```
【外观检验】
- 包装是否完整（无破损/变形/污染）
- 印刷是否清晰（logo/文字/颜色）
- 尺寸是否达标（长宽高/厚度）

【数量检验】
- 实际数量 vs 订单数量
- 允许误差范围（行业标准±3%）
- 计数方式（个/箱/件）

【功能检验】
- 实际承重 vs 标称承重
- 材质是否符合描述（纸箱材质/克重）
- 使用效果（组装是否顺畅）
```

## 质量问题分级

### 分级标准
| 等级 | 定义 | 影响 | 处理方式 |
|------|------|------|---------|
| 🚨 严重 | 不可用，无法实现预期功能 | 整批退货/索赔 | 立即处理+追责 |
| ⚠️ 一般 | 部分不符合，影响使用 | 降价/部分退货 | 协商处理 |
| ℹ️ 轻微 | 外观瑕疵，不影响功能 | 折价接受 | 记录复盘 |

### 常见问题判定
```python
质量问题_判定 = {
    "尺寸偏差>5%": "严重",
    "尺寸偏差2-5%": "一般",
    "尺寸偏差<2%": "轻微",
    "材质不符": "严重",
    "印刷模糊": "一般",
    "印刷偏色<10%": "轻微",
    "数量少5%以上": "严重",
    "数量少1-5%": "一般",
}
```

### 1688质量问题处理时限
- **签收后7天内**：可无理由退货
- **15天内**：质量问题退换货
- **超出时限**：需与商家协商

## 退货和退款流程

### 退货前准备
1. 拍照留证（外包装/内物/问题细节）
2. 联系供应商说明情况
3. 保留聊天记录作为证据
4. 在1688订单页面申请退款

### 退货申请步骤
```
1688订单页 → 申请退款 → 选择原因 →
上传凭证 → 等待商家确认 → 寄回货物 →
商家收货 → 退款到账
```

### 平台介入
当商家拒绝退款时：
1. 提供完整证据（照片/聊天记录/物流单）
2. 申请1688平台仲裁
3. 提供质检报告（如有必要）

## 供应商质量考核

### 考核周期
- **新供应商**：前3单重点跟踪
- **成熟供应商**：季度考核
- **问题供应商**：每月跟踪

### 考核维度
```markdown
## 供应商质量考核表

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 来料合格率 | 30% | 合格数量/交货数量 |
| 交期准确率 | 20% | 按时交货次数/总交货次数 |
| 问题响应速度 | 15% | 从反馈到解决的天数 |
| 配合度 | 15% | 退货/议价的配合程度 |
| 价格稳定性 | 10% | 是否有乱涨价 |
| 创新建议 | 10% | 是否有优化建议 |

综合得分 ≥ 80分：优秀（红榜）
综合得分 60-80分：合格（继续合作）
综合得分 < 60分：不合格（黑榜或淘汰）
```

### 与红黑榜联动
- 严重质量问题：直接进入黑榜
- 连续3次轻微问题：降级观察
- 主动改进且无问题：恢复红榜

## 与库存预警联动

### 质量问题导致库存异常
```
发现质量问题
  → 暂停使用该批次货物
  → 触发紧急采购（安全库存预警）
  → 质量货物到位后替换
  → 完成退货退款
```

### 安全库存重新计算
```python

    备货周期 += 3   # 额外3天备货周期
```
