# 高级提示词工程

## Overview

本技能覆盖高级提示词工程技术：思维链（Chain of Thought）、思想树（Tree of Thought）、自我反思、角色扮演、1688采购场景。适用于复杂推理、多方案评估、质量控制、专业场景对话。

---

## 1. 思维链 CoT 模板

### 1.1 标准 CoT 模板

适用于：数学计算、逻辑推理、多步骤分析

```
问题：[描述问题]

请按以下步骤推理：

步骤1：[分解问题第一个子目标]
分析：
推理：
结论：

步骤2：[分解问题第二个子目标]
分析：
推理：
结论：

步骤N：[最后综合]
综合分析：
最终结论：

验证：[用另一种方法或角度验证结论是否正确]
```

### 1.2 带示例 CoT（Few-shot CoT）

适用于：模型首次接触该类问题时

```
示例问题1：[简单例子]
解答步骤：
- 步骤1：[具体操作]
- 步骤2：[具体操作]
- 结论：[答案]

示例问题2：[稍复杂例子]
解答步骤：
- 步骤1：[具体操作]
- 步骤2：[具体操作]
- 结论：[答案]

你的问题：[实际问题]
请按照上述示例的推理方式，分步骤解答。
```

### 1.3 自洽性 CoT（Self-Consistency CoT）

适用于：需要高准确率的关键决策

```
问题：[描述问题]

请用3种不同的方法分别推理：

方法A：[第一种推理路径]
推理：
结论：

方法B：[第二种推理路径]
推理：
结论：

方法C：[第三种推理路径]
推理：
结论：

对比分析：
- 方法A和B的差异点：
- 哪个结论最可靠：
- 最终采纳结论：

置信度评估：[高/中/低] — 理由：
```

## 2. 思想树 ToT 模板

### 2.1 标准 ToT 模板

适用于：多方案权衡、创意评估、战略规划

```
目标：[描述最终目标]

请展开思维树：

                    [根节点：目标]
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   [方案A]            [方案B]            [方案C]
   优点：              优点：              优点：
   缺点：              缺点：              缺点：
   风险：              风险：              风险：
   所需资源：          所需资源：          所需资源：
        │                  │                  │
        ▼                  ▼                  ▼
   [子方案A1]         [子方案B1]         [子方案C1]
   [子方案A2]         [子方案B2]         [子方案C2]

评估维度：
- 成本：
- 时间：
- 风险：
- 收益：
- 可行性：

推荐路径：[选择及理由]
回溯检查：[该路径的潜在失败点和备选方案]
```

### 2.2 深度优先 ToT（用于复杂决策）

适用于：每个方案都需要深入分析的场景

```
问题：[核心问题]

阶段1：生成候选方案
- 方案1：[简述]
- 方案2：[简述]
- 方案3：[简述]

阶段2：评估每个方案（逐个深入）

方案1深度评估：
├── 当前状态分析：[现状]
├── 目标状态：[目标]
├── 关键步骤：
│   ├── 步骤1：[操作] → 结果：[预期] → 若失败：[回退方案]
│   ├── 步骤2：[操作] → 结果：[预期] → 若失败：[回退方案]
│   └── 步骤3：[操作] → 结果：[预期]
├── 资源需求：[资源列表]
├── 时间线：[阶段划分]
└── 风险登记：[风险1（概率/影响/缓解）| 风险2...]

[对方案2、3重复上述结构]

阶段3：对比与选择
对比表：
| 维度 | 方案1 | 方案2 | 方案3 |
|------|-------|-------|-------|
| 成本 |       |       |       |
| 时间 |       |       |       |
| 风险 |       |       |       |
| 收益 |       |       |       |
| 可行性|       |       |       |

推荐：[最优方案] — 理由：
次选：[备选方案] — 条件：
```

### 2.3 广度优先 ToT（用于快速头脑风暴）

适用于：需要穷举可能性、不遗漏任何选项

```
主题：[核心议题]

第1层 — 主要方向（至少5个）：
1. [方向A]
2. [方向B]
3. [方向C]
4. [方向D]
5. [方向E]

第2层 — 每个方向的分支（每个方向至少3个）：
方向A的分支：
├── A1：[具体选项]
├── A2：[具体选项]
└── A3：[具体选项]

[其他方向同理]

第3层 — 每个叶子节点的细节：
A1的细节：
- 实施难度：[高/中/低]
- 潜在收益：[具体描述]
- 依赖条件：[必要条件]
- 反对意见：[可能的质疑]

综合评估：
- 覆盖度检查：[是否覆盖了所有可能方向]
- 遗漏项补充：[补充项]
- 最优组合：[哪几个节点组合最优]

最终建议：[综合判断]
```

## 3. 自我反思提示词

### 3.1 答案验证反思

适用于：输出结果后主动检查

```
你刚才给出的答案：[引用你的答案]

请按以下维度自我审查：

1. 事实核查
   - 哪些信息有确凿来源？
   - 哪些信息是推测/推断？
   - 推测的置信度：[高/中/低]

2. 逻辑检查
   - 推理链条是否完整？
   - 是否有逻辑跳跃？
   - 因果关系是否成立？

3. 遗漏检查
   - 是否有重要角度被忽略？
   - 用户问题中哪些点未覆盖？

4. 偏见检查
   - 是否因为立场影响判断？
   - 是否有确认偏误？

5. 改进建议
   - 答案中哪部分最不可靠？
   - 如何修正最合理？

请给出修正后的答案（如果需要）。
```

### 3.2 过程反思（决策前使用）

适用于：重要决策前的自我审查

```
我即将做决定：[描述决定]

在给出答案前，请先思考：

1. 我真的理解问题了吗？
   - 用一句话重述问题：
   - 用户真正想知道的是什么？

2. 我的知识边界在哪？
   - 我确定知道的部分：
   - 我不确定的部分：
   - 我完全不知道的部分：

3. 常见陷阱检查
   - [ ] 是否在用直觉代替分析？
   - [ ] 是否被第一印象主导？
   - [ ] 是否忽略了反面证据？
   - [ ] 是否在合理化已有结论？

4. 替代方案
   - 除了这个答案，还有哪些可能？
   - 为什么我选这个而不是那个？

5. 不确定性声明
   - 这个答案的置信度：
   - 需要用户补充什么信息才能提高置信度？

基于以上反思，我的最终答案：
```

### 3.3 连续追问反思

适用于：多轮对话中保持反思习惯

```
回顾本次对话：

已确认的事实：
1. [事实1]
2. [事实2]

我的推理过程：
- 起点：[初始信息]
- 关键转折：[观点变化点]
- 终点：[当前结论]

我在哪里可能出错了？
- [最可能的错误点]
- [次可能的错误点]

用户还可以问哪些问题来验证我的判断？
1. [验证问题1]
2. [验证问题2]
```

## 4. 角色扮演提示词模板

### 4.1 专家顾问角色

适用于：需要深度专业知识的场景

```
你扮演 [专业角色]，例如：

## 角色设定

**身份**：[头衔/职位]
**专业领域**：[具体领域]
**经验年限**：[X] 年
**说话风格**：[严谨/通俗/简洁/详细]
**核心原则**：[最重要的专业信条]

## 能力边界

**擅长**：
- [具体技能1]
- [具体技能2]

**不擅长/不提供**：
- [明确边界]

## 回答框架

遇到问题时，你会：
1. 先了解背景（询问关键信息）
2. 给出专业判断（带置信度）
3. 解释推理过程（让用户理解决策依据）
4. 提供备选方案（当存在不确定性时）
5. 明确局限性（什么情况下建议寻求其他专家）

## 示例

用户问：[示例问题]
你回答：[示例回答风格]

## 开始

[用户的第一个问题]
```

### 5.2 价格谈判对话模板

适用于：与1688供应商议价

```
开场白：
"您好，我是 [公司名] 的采购负责人。我们正在寻找 [产品类目] 的稳定供应商，看贵店的产品和评价不错，想了解一下合作的可能性。"

---

谈判要点清单：

1. 了解底价
   话术："我们希望建立长期合作关系，请问您能给的最低价是多少？"
   目的：探出底价

2. 确认批量折扣
   话术："如果每月稳定采购 [数量]，能有多少折扣？"
   目的：获取量价挂钩

3. 了解成本结构（可选）
   话术："方便透露一下这个价格包含哪些服务吗？比如是否含税、含运费？"
   目的：横向比较

4. 争取保障条款
   话术："如果出现质量问题，退换货政策是怎样的？"
   目的：降低风险

5. 谈判收尾
   话术："综合考虑一下，最优能给我们什么价格？我们希望 [目标价位]，能达成的话可以先下一批试单。"
   目的：锁定优惠

---

谈判结果记录：
- 商品：[产品名]
- 起始价：[报价]
- 最终价：[谈下来的价格]
- 优惠幅度：[%]
- 其他附加条件：[条款]
- 下次联系预期：[时间]
```
