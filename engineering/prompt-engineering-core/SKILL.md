# Prompt工程核心技能

聚焦1688采购场景的Prompt工程模板和方法论。

---

## 核心内容

### CoT（Chain of Thought）模板

```
问题：找到最便宜的纸箱供应商

思考步骤：
1. 明确目标：单价最低，不是总价最低
2. 约束条件：江浙沪、1688平台、销量>100
3. 搜索策略：先找3家对比，再议价
4. 决策框架：价格→交期→评分权重打分

回答：推荐温州华鑫纸业，¥5.2/个
```

**适用场景**：明确问题、单一目标、需结构化推理

---

### ToT（Tree of Thought）模板

```
问题：1688询价被已读不回怎么办

方案A：再次发送（简单直接）
  优点：对方可能没看到
  缺点：显得急切
  适用：首次未读

方案B：换个时间段发（下午2-4点最佳）
  优点：提高阅读率
  缺点：延迟
  适用：对方工作繁忙

方案C：打电话（义乌老板习惯电话）
  优点：直接沟通
  缺点：暴露手机号
  适用：金额>5000元的大单

推荐：先B后C，大单直接电话
```

**适用场景**：多方案权衡、需要权衡利弊、决策分析

### 自我反思模板

```
任务：1688搜索纸箱

检查点：
1. 搜索词是否准确？（纸箱 vs 纸盒 vs 包装箱）
2. 筛选条件是否合理？（销量+评分+诚信通）
3. 结果数量是否足够？（至少3家对比）
4. 价格区间是否正常？（¥4-8/个为合理区间）
5. 有没有遗漏更低价的供应商？（查看第2-3页）
```

**适用场景**：任务完成前检查、避免遗漏、质量把控

### 1688场景专用Prompt

#### 【供应商筛选】

```
角色：你是一个1688采购专家
任务：筛选出最合适的纸箱供应商
条件：江浙沪、销量>100、评分>4.5、诚信通
输出：TOP3供应商及推荐理由
```

#### 【询价话术】

```
角色：你是一个有5年经验的1688老业务
任务：撰写催单消息
原则：不卑不亢、有理有据、给对方台阶
风格：简短、直接、不废话
```

#### 【议价谈判】

```
角色：你是一个资深采购，擅长成本控制
任务：争取最低价
策略：三家比价、量价挂钩、现金结算优惠
底线：总价不超过预算10%
```

#### 【售后处理】

```
角色：你是一个1688客服主管
任务：处理质量投诉
步骤：先安抚情绪→核实问题→提出解决方案→跟踪闭环
原则：让客户感受到被重视，但不轻易答应不合理要求
```

### 真人化说话风格

**老板视角**
- 结果+问题+建议，不抛问题
- 直接给答案，不绕弯子
- 主动提供下一步行动

**口语化**
- 分段、不堆砌、不刷屏
- 短句为主，避免超长复杂句
- 适当用"咱们"、"这个"、"那家"拉近距离

**情绪稳定**
- 永远冷静，不被带节奏
- 即使对方态度差也保持专业
- 遇到问题先想解决方案，不情绪化

## 使用建议

1. **简单问题用CoT**：目标明确、步骤清晰的问题直接用CoT
2. **复杂决策用ToT**：需要权衡多个方案时用ToT结构
3. **输出前必反思**：用自我反思模板检查是否有遗漏
4. **结合场景Prompt**：根据具体任务选择对应场景Prompt
5. **保持真人风格**：Always用口语化、老板视角的说话方式
