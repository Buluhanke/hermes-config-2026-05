# Decision Helper

结构化决策框架，量化评估可选方案。

## 适用场景
- 供应商选择
- 方案对比
- 优先级排序
- 风险评估

## 决策流程

### 1. 明确决策目标
- 核心诉求是什么？（价格最低？交期最快？质量最稳？）
- 有哪些硬性约束？（预算上限？时间底线？）
- 决策者是谁？（自己拍板还是给建议？）

### 2. 列出评估维度
根据场景选择相关维度，常用维度库：

| 维度 | 说明 | 权重参考 |
|------|------|---------|
| 价格/成本 | 直接金钱成本 | 高 |
| 质量/可靠性 | 产品质量/服务稳定性 | 高 |
| 交期/响应速度 | 交付时间/回复速度 | 中-高 |
| 配合度/沟通 | 响应态度/灵活度 | 中 |
| 稳定性/持续性 | 长期供货能力 | 中 |
| 资质/合规 | 认证/资质完备度 | 低-中 |

### 3. 评分矩阵

创建评分表（1-5分）：

| 选项 | 价格 | 质量 | 交期 | 配合度 | 稳定性 | 加权总分 |
|------|------|------|------|--------|--------|---------|
| 供应商A | 5 | 4 | 4 | 3 | 4 | 计算 |
| 供应商B | 4 | 5 | 3 | 5 | 3 | 计算 |
| 供应商C | 3 | 3 | 5 | 4 | 5 | 计算 |

**加权总分 = Σ(得分 × 权重)**

### 4. 敏感性分析
- 如果某个维度权重提高，哪个选项会胜出？
- 最低底线是多少？（价格不能超过X，质量必须≥Y）

### 5. 决策建议

\`\`\`
推荐：[选项名]

理由：
1. [核心优势1]
2. [核心优势2]

风险点：
- [需要注意的问题]

兜底方案：
如果[该选项]出现问题，备选：[备选名]
\`\`\`

## 快速决策模板（当选项≤3时）

**选项A vs 选项B vs 选项C**

| 维度 | 权重 | A | B | C |
|------|------|---|---|---|
| 价格 | 30% | | | |
| 质量 | 30% | | | |
| 交期 | 20% | | | |
| 配合 | 20% | | | |

**结论：** 直接给出推荐，不做过多分析，尊重用户时间。
