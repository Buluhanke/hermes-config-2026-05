# 结构化决策框架

## 概述

面对多个选项时，用结构化方法快速决策。不凭感觉，用数据说话。

## 决策树模板

### 基础决策流程
```
明确问题 → 收集选项 → 确定标准 → 评估选项 → 做决定

1. 明确问题：我要解决什么问题？
2. 收集选项：有哪些可能的方案？
3. 确定标准：用什么标准评估？（必须有主次之分）
4. 评估选项：每个方案在各标准的得分
5. 做决定：加权得分最高的方案
```

### 快速决策 vs 深度决策
- 快速决策（<5分钟）：三选一，直接选最优
- 深度决策（>1小时）：完整评估，列表打分

## 成本效益分析法

### 公式
```
净收益 = 收益 - 成本
收益比 = 收益 / 成本
```

### 示例：是否购买1688诚信通会员（年费6688元）
```
收益估算：
- 预计新增询价单：20单/月 × 10%转化 × 利润100元/单 = 200元/月 = 2400元/年
- 搜索排名提升带来曝光增加：约500元/年
- 信任背书价值：约1000元/年
总收益：约3900元/年

成本：6688元/年

结论：净收益 = 3900 - 6688 = -2788元，暂不推荐
```

## 风险评估矩阵

### 风险等级
| 概率 \ 影响 | 高 | 中 | 低 |
|-----------|---|---|---|
| 高 | 🔴 极高风险 | 🟠 高风险 | 🟡 中风险 |
| 中 | 🟠 高风险 | 🟡 中风险 | 🟢 低风险 |
| 低 | 🟡 中风险 | 🟢 低风险 | 🟢 极低风险 |

### 风险应对策略
- 规避：不做这件事
- 降低：采取行动减少概率或影响
- 转移：购买保险或对冲
- 接受：做好应急预案

## 1688场景决策案例

### 案例1：供应商选择

**选项**：
- A：温州华鑫，¥5.5/个，交期2天，评分4.6
- B：义乌星火，¥5.2/个，交期3天，评分4.4
- C：杭州鼎盛，¥5.8/个，交期1天，评分4.8

**评估标准（权重）**：
- 价格：35%
- 交期：25%
- 质量（评分）：25%
- 服务：15%

**评分**：
| 供应商 | 价格(35%) | 交期(25%) | 质量(25%) | 服务(15%) | 加权分 |
|-------|----------|----------|----------|----------|-------|
| A | 7(2.45) | 8(2.0) | 8(2.0) | 7(1.05) | 7.50 |
| B | 9(3.15) | 6(1.5) | 6(1.5) | 6(0.9) | 7.05 |
| C | 5(1.75) | 10(2.5) | 10(2.5) | 9(1.35) | 8.10 |

**结论**：选C（杭州鼎盛），综合得分最高

### 案例2：是否议价

**情境**：收到报价¥6.0/个，市场行情¥5.5-6.5

**决策树**：
```
报价是否明显高于市场？
├── 是（>¥6.5）→ 必须议价，至少砍到¥6.0
├── 否（¥5.5-6.5）→ 进入议价流程
│   ├── 订单量>1000 → 值得花时间议价
│   ├── 订单量<500  → 节省时间，直接下单
│   └── 老客户     → 根据关系深度判断
└── 否（<¥5.5）→ 价格已低，考虑是否加单
```

**建议**：批量500以上的订单值得花时间议价

### 案例3：是否实地考察

**决策条件**：
| 条件 | 说明 |
|------|------|
| 订单金额>1万 | 值得实地考察 |
| 供应商无认证 | 必须实地 |
| 有深度验厂报告 | 可省略 |
| 距离>100km | 成本高，需慎重 |
| 新供应商首单 | 建议实地 |

**建议**：
- 首单<5000元：远程验证即可
- 首单5000-10000元：根据风险评估决定
- 首单>10000元：建议实地考察
