# Logseq AI

## When to Use
使用Logseq做大纲笔记、知识管理时。需要AI辅助写作、块引用查询、或任务规划。Emacs用户尤为适合。

## Core Features
- **AI写作辅助**：润色、续写、摘要
- **块引用查询**：跨页面AI理解块级内容
- **任务规划**：AI辅助拆解任务
- **Emacs兼容**：Emacs内联编辑模式
- **双向链接**：与Obsidian互补的链接系统

## Quick Start
```bash
# 安装Logseq AI插件
# 设置 → 社区插件 → 搜索"logseq AI"

# 配置API（如OpenAI）
# Settings → AI →填写API Key

# 常用操作
# /ai 唤起AI命令
# 选中内容 → 右键 → AI Actions
```

## Pitfalls
- 插件生态不如Obsidian成熟
- AI功能依赖第三方插件
- Emacs模式配置较复杂
- 同步机制偶有不稳定
