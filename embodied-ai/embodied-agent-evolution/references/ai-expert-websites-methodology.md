# AI专家网站知识获取方法论

## 核心原则（2026-05-29确立）

遇到不熟悉的领域/问题，直接去AI网站客户端"请教"，像员工请教专家一样自然。
目的：让Hermes从"搜索引擎"进化成"有真人判断力的AI"——不懂就问，消化完再汇报。

## 适用场景

- 遇到技术问题不知如何下手 → 先问AI网站
- 需要行业知识/黑话/术语 → 直接问
- 想验证方案可行性 → 去问对比答案
- 不确定下一步怎么走 → 咨询智囊团
- **让Hermes进化成真人** → 像真人一样不懂就问，而不是遇事就搜索

## 与web_search的区别

| | web_search | AI专家网站咨询 |
|--|-----------|--------------|
| 速度 | 快（秒级） | 慢（加载+等生成） |
| 深度 | 浅 | 深，可追问 |
| 适用 | 快速事实 | 方案设计、思路、复杂问题 |

**原则**：日常快速问题用web_search，复杂问题/方向性问题用AI专家网站。
