# 1688 自封袋 sourcing 实战技法（2026-08-25）

## 完整运行配方（义乌 = 浙江省金华市 硬卡）

```bash
# 1) 起后台隐藏 CDP Chrome + 注入 1688/taobao 登录 cookie（不抢焦点）
cd ~/.hermes/skills/1688-search/1688-search-cn-gb-region-skill/scripts
bash start_cdp_1688.sh

# 2) 主跑：搜索 + 逐详情页核验（后台，不抢焦点）
python3 cdp1688_bag.py \
  --dims "14*20" \
  --cat "14*20cm白边12丝塑料自封袋" "14*20自封袋白边" "白边自封袋" "塑料自封袋" \
  --city 义乌 --prov "%D5%E3%BD%AD" \
  --pages 4 --gap 2.5 --maxverify 220 \
  --out store/bag_14x20_yiwu.json

# 3) 若末尾出现连续 5 次 LOGIN-WALL（登录态中途丢）→ 重注入 cookie 后补验剩余
bash start_cdp_1688.sh
python3 cdp1688_bag_reverify.py
```

> 注意：macOS **没有** `timeout` 命令，别写 `timeout 1500 python3 ...`（会 command not found）。裸跑 + `background=true` + `notify_on_complete`。

## 两个致命翻车点（已写入 SKILL.md 铁律）

1. **红边=白边**：只匹配"白边"二字会漏掉整批红边款。脚本白边信号必须含 红边/加宽边。
2. **厚度必须精确匹配那一条 SKU**：`775671146977` 被整页模糊并厚度误判成 12丝，实际 spec 是 10丝（白边）。只能从 `skuMapOriginal` 目标尺寸那条 specAttrs 抽厚度。
