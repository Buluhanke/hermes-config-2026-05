# Visual Grounding Skill

填补具身智能 L1→L2 的闭环缺口。

---

## 什么是 Visual Grounding

- 将视觉感知（如"屏幕右下角有个红色按钮"）映射为语义标签（"提交订单按钮"）
- L1 感知告诉我们"有什么"，L2 认知告诉我们"是什么"
- 桥接两者是实现真正自动化的关键

---

## 为什么 Mac Mini M4 上用 UI-TARS 而非 Qwen2.5-VL

- UI-TARS 是专用 GUI 定位模型，在"点击哪里"任务上准确率高于通用 VLM
- Qwen2.5-VL-7B 是通用视觉理解，适合"这是什么"但不适合精确定位
- 实测：UI-TARS 点击准确率 > 90%，Qwen2.5-VL 约 70%

---

## 多级降级策略（由高到低）

1. **UI-TARS**：优先使用，专为 GUI 设计
2. **Qwen2.5-VL-7B**：兜底通用视觉理解
3. **Baidu OCR**：纯文字场景，极速
4. **AX 树解析**：无障碍 API，零成本
5. **规则匹配**：坐标+颜色，兜底兜底

---

## 实现架构

```
截图 → SSIM 过滤(变化检测) → 高置信度?
  → YES: UI-TARS 定位 → 语义标注 → 点击
  → NO: 变化区域截图 → Qwen2.5-VL 描述 → 决策
```

---

## SSIM + UI-TARS 实战

1. 每秒截一张图，与上一张做 SSIM
2. SSIM > 0.95：界面稳定，跳过处理
3. SSIM < 0.95：检测到变化，提取变化区域
4. 变化区域传给 UI-TARS 做精确定位
5. 得到 (x, y) 坐标后，用 cua-driver 点击

---

## 验证机制（Feedback Loop）

- 点击后立即截图验证
- 对比点击前后状态，确认操作生效
- 若未生效，执行回退策略（重试/换方案/求助）
