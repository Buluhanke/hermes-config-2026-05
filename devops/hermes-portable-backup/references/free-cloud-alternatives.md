# 国内/外免费云盘对比(用户问过的 4 个)

> 触发词: "阿里云盘" / "百度网盘" / "TeraBox" / "123 云盘" / "免费云盘" / "其他云盘"
> 关键问题:**哪些能用 rclone 自动化?** (决定能不能"换电脑一键拉回来")

## 1 个原则决定一切: WebDAV

**rclone 自动化** = 用户零手动操作 = "换电脑一键恢复"的唯一路径

**rclone 自动化需要云盘支持 WebDAV(或 S3 兼容 API)。**

| 云盘 | WebDAV | rclone backend | 自动化 |
|------|--------|----------------|--------|
| 坚果云 | ✅ 原生 | webdav | ✅ |
| 123 云盘 | ❌ | 无 | ❌ 手动 |
| 阿里云盘 | ❌ | 无官方,只能 alidrive 库(非官方) | ⚠ 风险 |
| 百度网盘 | ❌ | 无官方,只能 baidupcs 库(非官方) | ⚠ 风险 + 限速 |
| TeraBox | ❌ | 无 | ❌ 手动 |
| iCloud Drive | ⚠(rclone 1.65+ 走 iclouddrive backend) | iclouddrive | ✅ |
| OneDrive | ✅(个人版 E2EE 不支持 WebDAV,但 rclone onedrive backend 走 OAuth) | onedrive | ✅ |
| GitHub | ❌ WebDAV,但 git 本身就是同步 | git | ✅ (但单文件 100MB 限制) |

**结论**:**国内"免费 + WebDAV + 能用"的只有坚果云**(没第二家)。

## 用户问过的 4 个 + 实际推荐

### 1. 阿里云盘(用户问过)

- 免费 100GB(限制下载速度 + 偶尔限速)
- 官方:无 WebDAV,无 S3 兼容 API
- 非官方:`alidrive` Python 库能用,但**违反 ToS**,账号有被封风险
- **结论**:不推荐做加密包备份(无法自动化 + 账号风险)

### 2. 百度网盘(用户问过)

- 免费 2TB,但**限速到 100KB/s** (下载 1GB 要 3 小时)
- 官方:无 WebDAV
- 非官方:`baidupcs-go` / `BaiduPCS-Py` 能用,但**账号风控严**,经常被封
- **结论**:**最不推荐** — 限速 + 风控 + 隐私

### 3. TeraBox(用户问过,容量王者 1TB 免费)

**详细分析**:
- ✅ 免费 1TB 永久(广告变现)
- ✅ 上传/下载不限速
- ❌ **无 WebDAV** — 只能手动网页/客户端
- ❌ **国内访问经常抽风**,要开代理
- ❌ 隐私条款允许扫描文件内容(**必须 GPG 加密后传**)
- ❌ 历史上有过"免费用户文件丢失"事件
- ❌ 不保证长期可用(海外公司,商业模型不稳)

**适用场景**:
- ✅ **异地兜底备份**(主备份在坚果云,兜底在 TeraBox,每月手动一次)
- ❌ 不做主备份(自动化做不到 = 容易忘)

**推荐用法**:
```bash
# 1. 跑 backup --no-upload(不传坚果云)
~/.hermes/scripts/hermes_backup.sh --no-upload

# 2. 打开 https://www.terabox.com → 上传
# 3. 把 staging/encrypted/hermes-*.tar.gz.gpg.part* 都拖到 /hermes-backups/ 目录
# 4. 验证:网页端能看到所有 .part 文件
```

### 4. 123 云盘(国内 WebDAV 缺失但容量大)

- 免费 2TB
- 单文件 100GB
- 无 WebDAV
- **结论**:跟百度/阿里同档 — 容量大但不能自动化,做"纯文档备份"可以,做加密包备份不行

## 怎么回答用户"哪个云盘好"

按用户场景对号入座:

| 用户场景 | 推荐 |
|----------|------|
| 想要"零成本 + 自动化 + 国内" | **坚果云免费版**,每周 1 份 (~129MB) |
| 能花 ¥199/年 | **坚果云专业版**,每天 1 份 + 保留 7 份 |
| Apple 生态重度 | **iCloud Drive 2TB** + GPG 加密 dmg |
| 想要"免费 + 大容量"做兜底 | **TeraBox** 每月手动一次(异地备份) |
| 想要"开源 + 可控 + 海外" | **S3 / Cloudflare R2** + rclone crypt |
| 只是存纯文档(.md / .pdf) | **百度/阿里/123** 都行,手动即可 |

## 反向思维: 为什么"必须 WebDAV"不是绝对必要

如果用户**愿意每月手动一次**,那"没 WebDAV"也能用 — 流程是:
1. 每月 1 号跑 `hermes_backup.sh --no-upload`
2. 网页端上传 3-5 个分卷
3. 每年花 5 分钟维护一次

但**绝大多数人会忘**。3 个月后第一次想恢复 = 备份是 2 个月前的 = 丢 2 个月对话记忆。

**所以"自动化"才是云盘选型的真正约束**,不是容量、不是速度。

## 实测数据(2026-06-06 用户机器)

- 坚果云 WebDAV 上传 129MB 加密包:30-60 秒
- rclone 增量同步,二次只传 diff
- 单向流量: ~130MB/周 (免费版 1GB/月够用)
- 双向流量: ~130MB/周 (恢复时拉)

## 终极建议(给用户的"真稳"组合)

| 备份类型 | 工具 | 月成本 | 恢复时间 |
|----------|------|--------|----------|
| 主力自动备份 | 坚果云 WebDAV + rclone | 免费或 ¥199/年 | 30 秒 |
| 异地兜底 | TeraBox 每月手动 | 免费 | 5-10 分钟(下载) |
| 离线备份 | 加密 U 盘(每月手动) | 一次性 ¥50 | 0(直接拔盘) |
| 极端兜底 | 1Password Secure Note 存 GPG 密码 + .env 加密 | $3/月 | 0(密码本) |

**3 异地 + 1 密码本** = 真稳。
