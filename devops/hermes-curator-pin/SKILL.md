# Curator Pin Guide

## When to use

- You have a custom/agent-created skill you want to keep permanently
- The skill is used infrequently (e.g. <1x per month) but high value when needed
- You want to prevent LLM umbrella-merge passes from consolidating it

## Commands

```bash
# See current status and pinned list
hermes curator status

# Pin a skill (agent-created only — bundled/hub-installed are auto-exempt)
hermes curator pin <skill-name>

# Unpin (Curator takes over management again)
hermes curator unpin <skill-name>

# Dry-run the curator to see what would happen
hermes curator run --dry-run

# Restore an archived skill
hermes curator restore <skill-name>
```

## Key facts

- **Scope**: Only agent-created skills (auto-generated by self-improvement loop)
- **Exempt**: Bundled skills (shipped with repo) and hub-installed (agentskills.io / skills.sh / ClawHub)
- **Never deletes**: Only archives to `~/.hermes/skills/.archive/` — always recoverable
- **CLI**: `hermes curator pin <skill>` and `hermes curator unpin <skill>`

## Status check format

```
curator: ENABLED
  runs:           6
  last run:       1d ago
  interval:       every 7d
  stale after:    30d unused
  archive after:  90d unused
  consolidate:    off (prune-only)
agent-created skills: 24 total
  active     24
  stale      0
  archived   0
```
