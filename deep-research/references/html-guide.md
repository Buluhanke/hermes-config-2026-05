# HTML 渲染指南

将研究报告 Markdown 渲染为单文件 HTML 网页。**精简优先**——只用必要的依赖和样式。

---

## 输出形式

- 单个 `.html` 文件，所有依赖通过 CDN 引入，浏览器直接打开即可运行
- 保存路径：`./reports/[研究标题简写]_[日期].html`

---

## 渲染前的内容处理

报告若较长（正文 > 8000 字），渲染前**先做一次按一级章节的浓缩**：

- 仅保留并输出原报告的"一级章节"，不输出二级或更细分小节编号
- 每个一级章节用 1-2 个高密度自然段总结，覆盖该章节所有小节的关键信息
- 完整保留：章节核心结论与主线判断、关键数据/事实/定量结论、支撑结论的逻辑链条
- 不引入原文未出现的新观点；不做跨章节综合判断
- 沿用原报告的分析逻辑与论证顺序；保持研究报告风格

若正文 ≤ 8000 字，直接整篇渲染，不需要浓缩。

---

## 技术栈（只用这些，不加新东西）

```html
<!-- Tailwind CSS -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Mermaid（仅当原文含 mermaid 代码块时引入） -->
<script src="https://cdn.jsdelivr.net/npm/mermaid/dist/mermaid.min.js"></script>

<!-- Apache ECharts（仅当原文含可结构化的统计数据时引入） -->
<script src="https://cdn.jsdelivr.net/npm/echarts/dist/echarts.min.js"></script>
```

> **不要**引入 Preline、Font Awesome、自定义字体等额外依赖。

---

## 页面结构（保持简单）

```
┌─────────────────────────────────────────┐
│  顶部吸顶标题栏（毛玻璃背景）            │
├──────────┬──────────────────────────────┤
│          │                              │
│  左侧    │       正文内容               │
│  TOC     │  （一级章节标题不入卡片，    │
│          │   二级小节用圆角卡片包裹）   │
│          │                              │
└──────────┴──────────────────────────────┘
```

- **响应式**：移动端 TOC 折叠为顶部抽屉或隐藏；桌面端固定在左侧
- **吸顶标题**：`position: sticky; top: 0;` + `backdrop-blur` 毛玻璃
- **一级章节**：纯标题，**不**包裹在卡片中
- **二级小节**：圆角卡片（`rounded-2xl` + `shadow-sm`），卡片内用 `border-t` 分割线分组
- **TOC**：自动锚点跳转，章节标题不折行

---

## 样式规范

- **字号梯度**：h1 ~24px、h2 ~20px、h3 ~18px、正文 16px、表格表体 ≤ 表头
- **配色**：低饱和度、淡雅；主色一种 + 中性灰阶。**不要**用强色块、霓虹色
- **留白**：段落间距适中，行距 1.6–1.8
- **表格**：列宽符合内容长度，避免标题或枚举折行
- **关键数据/标题**：可少量使用 Emoji 强调（一篇内 ≤ 10 处）

---

## 图表

- **Mermaid**：原文有 mermaid 代码块的，原样保留并由 mermaid.js 渲染
- **ECharts**：仅当原文给出明确结构化数据才生成；数据严格来自原文，**禁止编造**
- 图表样式与整体页面一致（简洁、低饱和、清晰标签）
- 容器响应式

---

## 编码与正文保真

- `<meta charset="UTF-8">`，无乱码
- 正文允许措辞层面的改写（合并重复句、优化表达），**禁止**摘要化或跨段落概括
- 章节标题沿用 Markdown 报告中的普通标题（无 C1/C2 前缀）

---

## 输出前自检

- [ ] 单文件 HTML，CDN 引入，可直接打开
- [ ] 一级章节全部出现，标题在卡片外
- [ ] 二级小节以圆角卡片承载
- [ ] 左侧 TOC 可点击跳转，移动端有合理替代方案
- [ ] 顶部吸顶 + 毛玻璃
- [ ] 表格无折行、字号正确
- [ ] 仅在原文有数据时生成 ECharts，无虚构数据
- [ ] 文件已保存到 `./reports/` 并告知用户路径
